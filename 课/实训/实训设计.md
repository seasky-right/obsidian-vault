# 光谱测量
1. 对不同空间位置的不同地物进行光谱测量，记录该地物属性、具体坐标、时间、太阳高度角，得到光谱反射率曲线；
2. 使用python脚本整理所有光谱反射率曲线数据，并使用辅助工具得到各个地物光谱对应4波段的光谱值
3. 在武汉一号（空间分辨率2.5m）遥感影像上找到对应坐标的4波段DN值并记录；
4. 使用优化的辅助工具，得到使用不同模型拟合得到的纠正参数；
5. 使用优化的辅助工具，得到对遥感影像进行纠正后的结果，并检验最终结果。

# 无人机正射影像成图
1. 使用DJI Matrices4E 设计航线并对测区进行正射影像采集，得到？张测区航拍影像
2. 在测区标注6个控制点6个检查点使用千寻RTK进行测量，记录点之记；
3. 导入控制点与检查点坐标，参考点之记在metashape中手动调整点位置至尽量准确坐标，控制像元误差和物元误差至可控范围；
4. 生成DEM（DOM）、建筑区域的正射影像和三维模型

# 激光点云
1. 使用手持SLAM对建筑内外表面进行激光测量，得到原始点云文件
2. 在RayStudio中对原始文件进行着色，导出pcd与las文件
3. 在CoProcess软件对点云文件进行处理，得到建筑三视图、横纵刨面
4. 在CoProcess中对刨面进行测量得到建筑不同区域的测量结果

# GNSS控制网测量
1. 在3个测区分别选择共16个控制点，由2个班11个组对6+5+6个点进行控制点RTK采集与静态测量，其中5个点不动，引入两组每组共6个点与5个点构成两个闭合环；
2. 再将静态数据导入HGO软件进行基线处理，不合格基线调整天线角进行再次处理使其合格；
3. 然后进行三维自由网平差；再选取3个控制点，其中两个填入RTK的三个坐标，一个只填入RTK的高程坐标进行高程拟合，得到二维约束平差结果；
4. 最后对比二维约束平差结果与RTK结果得到最终表格。
