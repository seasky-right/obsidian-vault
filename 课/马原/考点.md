## 2. 唯物史观

1. **社会存在与社会意识**
	- 社会存在是社会物质生活条件，是社会生活的物质方面。
	- 社会意识是社会存在的反映，是社会生活的精神方面。
	- 社会存在决定社会意识：
		- 社会存在是社会意识内容的客观来源。
		- 社会意识根源于社会存在，是对现实社会生活的反映。
		- 社会存在变化发展，社会意识也会相应变化发展。
	- 社会意识具有相对独立性：
		- 第一，社会意识与社会存在发展具有不完全同步性和不平衡性。
		- 第二，社会意识内部各种形式之间相互影响，并具有历史继承性。
		- 第三，社会意识对社会存在具有能动反作用。
	- 意义：
		- 理论上，正确回答社会历史观基本问题，宣告唯心史观破产。
		- 实践上，要求从现实社会存在出发制定政策，同时重视先进社会意识的引领作用。
2. 物质资料的生产方式是社会发展的决定性力量
3. **生产力与生产关系**
	- 生产力是人类改造和影响自然以满足社会需要的物质力量。
	- 生产关系是人们在物质生产过程中形成的不以人的意志为转移的经济关系。
	- 生产力决定生产关系。
	- 生产关系对生产力具有反作用。
4. **经济基础与上层建筑**
	- 经济基础是由社会一定发展阶段的生产力所决定的生产关系的总和。
	- 上层建筑是建立在一定经济基础之上的意识形态以及相应制度、组织和设施。
	- 经济基础决定上层建筑。
	- 上层建筑对经济基础具有反作用。
5. 交往
6. 社会形态更替
	- 统一性与多样性
	- 必然性与选择性
7. **社会基本矛盾与社会主要矛盾**
	- 社会基本矛盾
		- 是贯穿社会发展过程始终，规定社会发展基本性质和趋势，并对社会历史发展起根本推动作用的矛盾。
		- 生产力和生产关系、经济基础和上层建筑的矛盾，是社会基本矛盾。
		- 作用：
			- 第一，生产力是社会基本矛盾运动中最基本的动力因素，是社会发展和进步的最终决定力量。
			- 第二，社会基本矛盾决定社会中其他矛盾的存在和发展。
			- 第三，社会基本矛盾具有不同表现形式和解决方式，从根本上影响社会形态变化发展。
	- 社会主要矛盾
		- 社会主要矛盾是在社会发展一定阶段中处于支配地位、起主导作用的矛盾。
		- 社会主要矛盾是社会基本矛盾的具体体现。
		- 社会主要矛盾变化，会使社会发展呈现新的阶段性特点。
	- 运用：深化改革
8. 社会进步与人的发展
	- 社会进步表现于：社会形态从低级向高级发展，同一社会形态内部不断发展完善。
	- 人的发展阶段：
		- 第一，人的依赖关系占统治地位的阶段。

	- 二者关系

		- 人的发展也是衡量社会进步的重要尺度。
9. 改革的作用
	- 改革是一定社会为解决社会基本矛盾而对生产关系和上层建筑进行的深刻调整，是社会制度的自我调整和完善。
10. **科学技术的作用**

		- 第一，人民群众是社会物质财富的创造者。
		- 第二，人民群众是社会精神财富的创造者。

# 二、资本论

1. 劳动力商品的二因素
2. **剩余价值**
	- 资本运动的目的不是获得使用价值，而是实现价值增殖。
	- 剩余价值既不能从流通中产生，又不能离开流通而产生。
3. **绝对剩余价值 / 相对剩余价值**
	- 绝对剩余价值是在必要劳动时间不变的条件下，通过延长劳动日长度而生产的剩余价值。
	- 相对剩余价值是在工作日长度不变的条件下，通过缩短必要劳动时间、相对延长剩余劳动时间而生产的剩余价值。
	- 缩短必要劳动时间依赖于全社会劳动生产率提高。
	- 资本家追逐超额剩余价值，推动全社会劳动生产率提高，从而形成相对剩余价值生产条件。
4. **资本积累**
	- 把剩余价值转化为资本，或者说剩余价值资本化的过程，称为资本积累。
	- 资本积累的源泉是剩余价值。
	- 资本积累的本质，是资本家利用无偿占有的剩余价值扩大资本规模，进一步加强对工人的剥削和统治。
5. **资本循环**
	- 资本循环的三个阶段：
		- 第一，购买阶段：货币资本购买生产资料和劳动力。
		- 第二，生产阶段：生产资料和劳动力结合，生产商品并创造剩余价值。
		- 第三，售卖阶段：商品资本转化为货币资本，实现价值和剩余价值。
	- 资本正常循环的条件：
		- 第一，三种资本形式在空间上并存。
		- 第二，三个循环阶段在时间上继起。
		- 第三，各阶段比例协调、顺利转化，不能长期停滞在某一阶段。
6. **资本主义基本矛盾与经济危机**
	- 资本主义基本矛盾是生产社会化和生产资料资本主义私人占有之间的矛盾。
	- 资本主义经济危机的实质是生产相对过剩。
	- 资本主义生产无限扩大的趋势与劳动人民有支付能力需求相对有限之间的矛盾，必然导致危机。
	- 资本主义基本矛盾运动具有阶段性，导致经济危机周期性爆发。
	- 危机、萧条、复苏、高涨构成资本主义再生产周期。
7. **资本主义民主制度本质**
	- 建立在资本主义经济基础之上，反映资产阶级的政治要求，并反过来保护资本主义经济基础。
8. 资本主义意识形态
	- 私有制神圣不可侵犯观念。
	- 个人主义价值观。
9. 第二次世界大战后资本主义的新变化及其实质
	- 科学技术革命和生产力发展，是根本推动力量。
	- 工人阶级争取自身权利和利益的斗争，是重要力量。
	- 社会主义制度显示的优越性，对资本主义产生影响。
	- 改良主义政党对资本主义制度的改革，也起到一定作用。
10. 当代资本主义变化的新特征
	- 第一，科技创新加速资本主义生产方式变化。
	- 第二，国际金融垄断资本主义影响日益显现。
	- 第三，社会阶级阶层结构呈现复杂性、多样化。
	- 第四，发达资本主义国家凭借经济、科技、文化传播等优势，在世界范围内推行霸权主义和强权政治。
	- 当代资本主义的新特征说明资本主义具有一定自我调节能力，但没有改变其制度本质和基本矛盾。
11. 世界大变局下资本主义的矛盾与冲突
	- 经济发展失调
	- 政治体制失灵
	- 社会融合机制失效
	- 这些乱象的深层原因和根源，归根到底在于资本主义制度本身，在于资本主义基本矛盾。
12. 垄断资本主义
13. 经济全球化

# 三、科学社会主义

1. **科学社会主义基本原则**
	 - 第一，资本主义必然灭亡，社会主义必然胜利。
	- 第二，无产阶级是最先进最革命的阶级，肩负推翻资本主义旧世界、建立社会主义和共产主义新世界的历史使命。
	- 第三，无产阶级革命是无产阶级斗争的最高形式，以建立无产阶级专政的国家为目的。
	- 第四，要在生产资料公有制基础上组织生产，以满足全体社会成员需要为生产根本目的。
	- 第五，要对社会生产进行有计划的指导和调节，实行按劳分配原则。
	- 第六，要合乎自然规律地改造和利用自然，努力实现人与自然和谐共生。
	- 第七，必须坚持科学理论指导，大力发展社会主义先进文化。
	- 第八，无产阶级政党是无产阶级先锋队，社会主义事业必须坚持无产阶级政党的领导。
	- 第九，社会主义社会要大力解放和发展生产力，逐步消灭剥削和消除两极分化，实现共同富裕和社会全面进步，并最终向共产主义过渡。
	- 第十，共产主义是人类最美好的社会，实现共产主义是共产党人的最高理想。
	- 方法论：
		- 必须始终坚持科学社会主义一般原则
		- 必须同本国实际相结合
		- 必须随着时代和实践发展而丰富发展
2. **中国特色社会主义与科学社会主义**
	- 中国特色社会主义坚持科学社会主义基本原则
		- 坚持党的领导。
		- 坚持社会主义制度。
		- 坚持人民主体地位。
		- 坚持共同富裕方向。
		- 坚持共产主义远大理想。
3. **共产主义社会基本特征**
	- 物质财富极大丰富，消费资料按需分配
	- 社会关系高度和谐，人们精神境界极大提高
	- 实现每个人自由而全面的发展
4. 远大理想与共同理想
