# 考点一：向量代数及其运算

1. 【2007-2008·一、1】设有向量 $\vec{a}=\{0,4,-3\}$, $\vec{b}=\{4,-5,0\}$, 求 $\text{Prj}_{\vec{a}}\vec{b}$。
    
    - 【考点】向量在另一个向量上投影的直接计算公式。
        
    - 【答案】-4。
        
2. 【2008-2009·一、5】已知 $\vec{a}=(1,1,-4)$, $\vec{b}=(1,-2,2)$, 试求 $\vec{a}$ 在 $\vec{b}$ 上的投影。
    
    - 【考点】向量投影计算与向量模长的求法。
        
    - 【答案】-3。
        
3. 【2009-2010·一、4】设向量 $\vec{a}=(2,-3,1)$, $\vec{b}=(1,-2,3)$, $\vec{c}=(2,1,2)$，求同时垂直于 $\vec{a}$ 和 $\vec{b}$，且在向量 $\vec{c}$ 上投影是 14 的向量 $\vec{d}$。
    
    - 【考点】综合应用向量的外积（叉乘）求公垂向量，结合投影条件定标量系数。
        
    - 【答案】$\vec{d}=(14,10,2)$。
        
4. 【2012-2013·一、1】设 $\vec{a}=\{3,-3,4\}$, $\vec{b}=\{3,6,2\}$, 求 $(2\vec{a}+\vec{b})\cdot(2\vec{a}-\vec{b})$ 及 $(3\vec{a}-2\vec{b})\times(5\vec{a}-4\vec{b})$。
    
    - 【考点】向量的线性运算、数量积的平方差公式、向量积（叉积）的分配律展开。
        
    - 【答案】前者为 87；后者为 $6\{10,-2,-9\}$（即 $\{60,-12,-54\}$）。
        
5. 【2014-2015·一、1】设 $\vec{p}=2\vec{a}+\vec{b}$, $\vec{q}=k\vec{a}+\vec{b}$，其中 $|\vec{a}|=1$, $|\vec{b}|=2$，且 $\vec{a}\perp\vec{b}$，问：(1) $k$ 为何值时，$\vec{p}\perp\vec{q}$？ (2) $k$ 为何值时，以 $\vec{p},\vec{q}$ 为边的平行四边形面积为 6？
    
    - 【考点】向量垂直的点乘条件，以及平行四边形面积与叉乘模长几何意义的代数转换。
        
    - 【答案】(1) $k=-2$；(2) $k=5$ 或 $k=-1$。
        
6. 【2015-2016·一、1】设长方体三条棱长为 $|OA|=5$, $|OB|=3$, $|OC|=4$, $OM$ 为对角线，求 $\vec{OA}$ 在 $\vec{OM}$ 上的投影。
    
    - 【考点】空间直角坐标系建模，空间向量及其投影的几何与代数结合。
        
    - 【答案】$\frac{5\sqrt{2}}{2}$。
        
7. 【2016-2017·一、1】单位圆的圆周上有相异两点 $P,Q$, $\angle POQ=\theta$, $a,b$ 为正的常数，求 $\lim_{\theta\to0}\frac{1}{\theta^2}[a+b-|a\vec{OP}+b\vec{OQ}|]$。
    
    - 【考点】利用余弦定理计算向量合成的模长，并结合泰勒公式或洛必达法则求极限的综合运用。
        
    - 【答案】$\frac{ab}{2(a+b)}$。
        
8. 【2017-2018·一、4】已知 $A(1,0,0), B(0,2,1)$，试在 $z$ 轴上求一点 $C$，使 $\Delta ABC$ 的面积最小。
    
    - 【考点】利用向量外积的模长表示空间三角形面积，转化为一元函数求极值最值问题。
        
    - 【答案】点 $C$ 坐标为 $(0,0,\frac{1}{5})$。
        
9. 【2018-2019·一、1】已知 $|\vec{a}|=2, |\vec{b}|=3, (\widehat{\vec{a},\vec{b}})=\frac{\pi}{6}$，试求以向量 $\vec{A}=5\vec{a}+2\vec{b}, \vec{B}=\vec{a}-3\vec{b}$ 为边的平行四边形的面积。
    
    - 【考点】利用向量外积运算律将混合向量叉乘展开化简，利用夹角公式求模长。
        
    - 【答案】51。
        
10. 【2020-2021·一、1】已知 $\alpha,\beta$ 都是单位向量，夹角是 $\frac{\pi}{3}$, 求向量 $2\alpha+\beta$ 和 $-3\alpha+2\beta$ 的夹角。
    
    - 【考点】利用数量积求点乘，利用向量积求叉乘模长，并通过三角函数比值求解空间夹角。
        
    - 【答案】$\frac{2\pi}{3}$。
        
11. 【2021-2022·一、1】已知向量 $\vec{a}, \vec{b}$ 满足 $|\vec{a}|=\sqrt{2}, |\vec{b}|=2, |\vec{a}+\vec{b}|=\sqrt{10}$，求 $|\vec{a}-\vec{b}|$。
    
    - 【考点】向量模长平方与数量积的恒等式关系转换。
        
    - 【答案】$\sqrt{2}$。
        
12. 【2022-2023·一、1】已知向量 $\vec{b}=(2,3,4)$，且 $|\vec{a}|=10$，若向量 $\vec{a}$ 与 $\vec{b}\times\vec{i}$ 同向（或反向），求 $\vec{a}$。（注：基于考点解析复原了题干的扫描缺损）
    
    - 【考点】向量的叉积计算，及已知模长和方向求原向量（向量的单位化与数乘）。
        
    - 【答案】$\vec{a}=\pm(0,8,-6)$。
        

# 考点二：平面及其方程

1. 【2007-2008·一、2(2)】已知直线 $L:\begin{cases}2x+y=0\\ 4x+2y+3z=6\end{cases}$ 和曲面 $\Sigma:x^2+y^2+z^2=6$，求通过直线 $L$ 且与曲面 $\Sigma$ 在点 $(1,2,-1)$ 处的法线平行的平面方程。
    
    - 【考点】平面束方程（平面铅笔）的应用，直线与平面平行的法向量约束（结合了后续切平面的法向量计算）。
        
    - 【答案】$2x+y+4z-8=0$。
        
2. 【2008-2009·一、3】求过平面 $x+5y+z=0$ 和 $x-z+4=0$ 的交线且与平面 $x-4y-8z+12=0$ 成 $\frac{\pi}{4}$ 角的平面方程。
    
    - 【考点】平面束方程设参，两平面夹角余弦公式解参。
        
    - 【答案】$x-z+4=0$ 和 $x+20y+7z-12=0$。
        
3. 【2009-2010·一、2】求过直线 $\frac{x-2}{5}=\frac{y+1}{2}=\frac{z-2}{4}$, 且与平面 $x+4y-3z+1=0$ 垂直的平面方程。
    
    - 【考点】直线一般式转平面束方程，利用法向量互相垂直求参数。
        
    - 【答案】$22x-19y-18z-27=0$。
        
4. 【2012-2013·一、2】求 $A,B$ 的值，使平面 $\pi:Ax+By+6z-7=0$ 与直线 $l:\frac{x-4}{2}=\frac{y+5}{-4}=\frac{z+1}{3}$ 垂直。
    
    - 【考点】直线与平面垂直的充要条件（即直线的方向向量与平面的法向量平行）。
        
    - 【答案】$A=4, B=-8$。
        
5. 【2013-2014·一、3】求过点 $M(1,-2,3)$ 的平面，使它与平面 $\pi:x+y-z-3=0$ 垂直，且与直线 $L:x=y=z$ 平行。
    
    - 【考点】平面的点法式方程应用，由题意两个已知方向求外积获得平面的法向量。
        
    - 【答案】$x-y-3=0$。
        
6. 【2017-2018·一、6】求过直线 $\begin{cases}2x-y-2z+1=0\\ x+y+4z-2=0\end{cases}$ 并在 $y$ 轴和 $z$ 轴上有相同的非零截距的平面方程。
    
    - 【考点】利用平面束建立方程，并根据坐标轴截距相等的条件定参。
        
    - 【答案】$7x-2y-2z+1=0$。
        

# 考点三：空间直线及其方程

1. 【2014-2015·一、6】设直线 $l_1:\frac{x+2}{1}=\frac{y-3}{-1}=\frac{z+1}{1}, l_2:\frac{x+4}{2}=\frac{y}{1}=\frac{z-4}{3}$, 试求与直线 $l_1,l_2$ 都垂直且相交的直线的方程。
    
    - 【考点】异面直线的公垂线求法，构建两个分别包含已知直线且共用法向量（公垂方向）的平面。
        
    - 【答案】$\begin{cases}2x+7y+5z-12=0\\ 3x-9y+z+8=0\end{cases}$。
        
2. 【2015-2016·一、11】设有直线 $l_1:\frac{x}{4}=\frac{y}{1}=\frac{z}{1}, l_2:\begin{cases}z=5x-6\\ z=4y+3\end{cases}, l_3:\begin{cases}y=2x-4\\ z=3y+5\end{cases}$，求平行于 $l_1$ 而分别与 $l_2, l_3$ 相交的直线的方程。
    
    - 【考点】相交直线的空间几何条件，通过分别设立含已知直线的平面束并要求平面平行于目标方向求解。
        
    - 【答案】$\begin{cases}15x-76y+16z-75=0\\ 4x-23y+5z-43=0\end{cases}$。
        
3. 【2016-2017·一、3】求过点 $M(-4,-5,3)$，且与两条直线 $l_1:\frac{x+1}{3}=\frac{y+3}{-2}=\frac{z-2}{-1}$ 和 $l_2:\frac{x-2}{2}=\frac{y+1}{3}=\frac{z-1}{-5}$ 都相交的直线方程。
    
    - 【考点】过空间定点作两异面直线相交线，利用定点与已知直线分别确定两个平面，两平面交线即为所求。
        
    - 【答案】$\begin{cases}x+3z-5=0\\ 7x-13y-5z-22=0\end{cases}$。
        
4. 【2019-2020·二、3】考察两直线 $l_1:\frac{x+1}{2}=\frac{y-1}{1}=\frac{z}{-3}$ 和 $l_2:\begin{cases}x=4t+2\\ y=-t+3\\ z=2t-4\end{cases}$ 是否相交？如相交，求出其交点；如不相交，求出两直线之间的距离 $d$。
    
    - 【考点】异面直线的判定，异面直线距离的混合积求法（即平行六面体体积除以底面积）。
        
    - 【答案】两直线不相交（为异面直线）；距离 $d=\frac{11}{\sqrt{293}}$。
        

# 考点四：直线与平面的综合关系

1. 【2018-2019·一、5】确定 $\lambda$，使直线 $L:\frac{x-1}{1}=\frac{y+2}{2}=\frac{z-1}{\lambda}$ 平行于空间曲线 $x=t, y=t^2, z=\frac{1}{3}t^3$ 在 $t=1$ 处的切线，并求直线 $L$ 在平面 $\pi_2:x-y+z-2=0$ 上的投影直线方程。
    
    - 【考点】利用曲线切向量定参，结合通过直线作已知平面垂面的方法求投影直线。
        
    - 【答案】$\lambda=1$；投影直线方程为 $\begin{cases}x-z=0\\ x-y+z-2=0\end{cases}$。
        
2. 【2020-2021·一、6】证明直线 $L_1:\begin{cases}\frac{x-3}{4}=\frac{z+1}{-3}\\ y=2\end{cases}$ 与直线 $L_2:\frac{x}{2}=\frac{y-1}{2}=\frac{z-1}{-1}$ 相交，并求由它们所确定的平面方程。
    
    - 【考点】直线相交的解析证明，两条相交直线点法式平面的建立。
        
    - 【答案】证明思路：联立参数解出唯一公共交点 $(1,2,\frac{1}{2})$，且二者方向不平行从而相交；确定的平面方程为 $3x-y+4z-3=0$。
        
3. 【2021-2022·一、13】用平面束方法求解：求过点 $P(1,1,1)$ 且与直线 $L_1:x+1=\frac{y-1}{2}=\frac{z}{-1}$ 垂直相交的直线 $L$ 的一般方程。
    
    - 【考点】利用平面束方程巧妙求过直线且含定点的平面，将其与法平面联立得到直线的普通方程。
        
    - 【答案】$\begin{cases}x+2y-z-2=0\\ 2x-3y-4z+5=0\end{cases}$。
        
4. 【2022-2023·一、2】求直线 $l:\frac{x-2}{0}=\frac{y}{-1}=\frac{z+1}{1}$ 在平面 $2x-y+2z-1=0$ 上的投影直线的方程。
    
    - 【考点】空间投影直线的求解方法（通过已知直线构筑投影面）。
        
    - 【答案】投影直线方程为 $\begin{cases}2x-y+2z-1=0\\ x-2y-2z-4=0\end{cases}$。
