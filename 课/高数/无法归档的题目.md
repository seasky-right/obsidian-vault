# 考点一：常微分方程的求解与综合应用

1. 【2007-2008·一、6】求微分方程 $y'' - 4y' + 3y = 0$ 满足初始条件 $y(0)=2, y'(0)=4$ 的特解。
    
    - 【考点】二阶常系数齐次线性微分方程的特征方程法与初值问题的求解。
        
    - 【答案】$y = e^x + e^{3x}$。
        
2. 【2009-2010·一、5】求一阶线性微分方程 $y' - \frac{1}{x}y = x^2 \sin x$ 的通解。
    
    - 【考点】一阶线性非齐次微分方程，利用常数变易法或积分因子法求解。
        
    - 【答案】$y = x(C - \cos x)$。
        
3. 【2013-2014·三】设平面曲线 $L: y=y(x)$ 过点 $(1, 2)$，且其上任意一点 $P(x,y)$ 处的切线在 $y$ 轴上的截距等于该点横坐标的平方，求此曲线的方程。
    
    - 【考点】利用导数的几何意义（切线方程与截距）建立一阶线性常微分方程，并结合初值求解特解。
        
    - 【答案】$y = x^2 + x$。
        
4. 【2015-2016·七】求微分方程 $y'' + 2y' + y = x e^{-x}$ 的通解。
    
    - 【考点】二阶常系数非齐次线性微分方程，特征根为二重根，右端项为“多项式×指数函数”形式时特解的设法（需乘以 $x^2$）。
        
    - 【答案】$y = (C_1 + C_2 x)e^{-x} + \frac{1}{6}x^3 e^{-x}$。
        
5. 【2019-2020·三】设函数 $f(x)$ 连续，且满足积分方程 $\int_0^x f(t)dt = x + \int_0^x t f(x-t)dt$，求 $f(x)$ 的解析式。
    
    - 【考点】利用变限积分求导法则和换元法（或拉普拉斯变换）消除积分号，将其转化为常微分方程求解。
        
    - 【答案】$f(x) = e^x$。
        
6. 【2021-2022·四】求微分方程 $x y' + y = y^2 \ln x$ 的通解。
    
    - 【考点】伯努利（Bernoulli）方程的标准化及变量代换法（令 $u = y^{-1}$ 转化为一阶线性微分方程）。
        
    - 【答案】$y = \frac{1}{C x + \ln x + 1}$。
        

# 考点二：含参变量积分及其导数计算

1. 【2011-2012·五】设 $I(a) = \int_0^\infty \frac{e^{-ax} - e^{-bx}}{x} dx$ ($a>0, b>0$)，利用含参变量积分的求导法则计算 $I(a)$。
    
    - 【考点】在广义积分中利用莱布尼茨公式对参变量 $a$ 求导以消去分母 $x$，求出导函数后再积分还原。
        
    - 【答案】$I(a) = \ln\frac{b}{a}$。
        
2. 【2016-2017·十二】设 $F(y) = \int_0^1 \ln(x^2 + y^2) dx$ ($y>0$)，求导数 $F'(y)$。
    
    - 【考点】含参变量定积分在无瑕点区间内对参数求导，随后计算基础的有理函数定积分。
        
    - 【答案】$F'(y) = 2 \arctan\frac{1}{y}$。
        
3. 【2022-2023·五】求极限 $\lim_{t\to 0} \frac{1}{t} \int_0^t \frac{\sin(xy)}{y} dy$。
    
    - 【考点】结合洛必达法则处理 $\frac{0}{0}$ 型极限，利用含参变量的变限积分求导规则。
        
    - 【答案】$x$。
        

# 考点三：场论初步（散度、旋度与势函数）

1. 【2008-2009·九】求向量场 $\vec{A} = x^2 y \vec{i} + y^2 z \vec{j} + z^2 x \vec{k}$ 在点 $(1, -1, 2)$ 处的散度 ($\text{div} \vec{A}$) 与旋度 ($\text{rot} \vec{A}$)。
    
    - 【考点】空间向量场散度（偏导数之和）与旋度（利用哈密顿算子 $\nabla$ 求叉乘）的定义式直接代入计算。
        
    - 【答案】散度为 $1$；旋度为 $-\vec{i} - 4\vec{j} + \vec{k}$。
        
2. 【2014-2015·十】验证向量场 $\vec{F} = (2xy + z^2)\vec{i} + x^2\vec{j} + 2xz\vec{k}$ 为保守场（无旋场），并求其势函数 $u(x,y,z)$。
    
    - 【考点】验证旋度恒为零向量（即 $\text{rot} \vec{F} = \vec{0}$），并通过偏积分法或空间平行坐标轴折线积分法求原函数。
        
    - 【答案】证明旋度为零略；势函数 $u(x,y,z) = x^2y + xz^2 + C$。
        
3. 【2020-2021·十四】设空间速度场 $\vec{v} = \vec{\omega} \times \vec{r}$，其中 $\vec{\omega} = \{ \omega_1, \omega_2, \omega_3 \}$ 为常向量，向径 $\vec{r} = \{ x, y, z \}$。求证：$\text{rot} \vec{v} = 2\vec{\omega}$。
    
    - 【考点】向量叉积的坐标展开式与旋度行列式算子的结合应用证明。
        
    - 【答案】证明思路：先写出叉积坐标形式 $\vec{v} = (\omega_2 z - \omega_3 y)\vec{i} + (\omega_3 x - \omega_1 z)\vec{j} + (\omega_1 y - \omega_2 x)\vec{k}$，代入旋度计算公式分别对 $x,y,z$ 提取偏导，化简后即得 $2\omega_1\vec{i} + 2\omega_2\vec{j} + 2\omega_3\vec{k}$。
