- Kruskal算法：加边法，更适合稀疏图

# 红黑树

- **性质**：左根右，根叶黑，不红红，黑路同
	- 最长路径不超过最短路径的两倍
- 插入：
	- 插入节点默认为红色
	- 插入节点是根结点 -> 直接变黑
	- 插入节点的叔叔是红色 -> 上三个节点变色，继续检查爷爷
	- 插入节点的叔叔是黑色 -> 旋转后变色（最后一次旋转点与最后中心点）

# B树
- 特点：平衡，有序，多路
- ![[Pasted image 20260616192458.png|281]]
- 查找：
	- 访问节点在硬盘上进行
	- 节点内的查找在内存中进行
- 插入：
	- 先查找到插入的位置进行插入
	- 如果出现上溢出，中间元素$[\frac m 2]$上移，两边分裂
	- 直到没有上溢出为止
- 删除：
	- 非叶结点：利用前驱/后继替换
	- 叶子结点（出现下溢出）：
		- 兄弟够借：父下来兄上去
		- 兄弟不够借：父下移到左，然后右并过来

# 哈希表

- 散列函数：
	- 1. 直接定址法 -> 适合关键字连续的情况
	- 2. 除留余数法
		- p一般取小于等于表长的最大质数
		- 可能出现冲突
			- 影响性能的因素：散列函数、装填因子、处理冲突的方法

- 冲突处理的方法：
	- 开放定址法：
		- 线性定址法：冲突后依次探测下一个位置直到遇到空闲位置（表尾的下一个位置是表首）
			- 容易出现聚集（堆积）
			- 删除需要加入删除标记
		- 平方探测法：冲突时按照±平方整数的顺序进行探测
			- 优点：可以缓解堆积问题
			- 缺点：不一定能探测到所有位置
				- 表长为某个4k+3的质数时一定可以全部探测
			- 删除需要加入删除标记
	- 拉链法：把所有的同义词用链表串起来

# 排序

### 插入排序
- 优点：
	- 稳定性（希尔排序不稳定）
	- 数据基本有序时效率较高
	- 数据量相对少时效率较高
- 最好时间复杂度：$O(n)$
- 最坏时间复杂度：$O(n^2)$

### 快速排序
- 不稳定
- 最好时间复杂度：$O(n\log_2 n)$
- 最坏时间复杂度：$O(n^2)$
- 空间复杂度：$O(\log_2 n)$

# 堆
- 前提：完全二叉树
- 大根堆：结点值大于左右孩子
- 小根堆：结点值小于左右孩子
- 存储：顺序结构(1-base)
	- i号节点：
		- 左孩子：$2i$
		- 右孩子：$2i+1$
		- 父亲：$\left[\frac{i}{2}\right]$
