# 一、几个主要矛盾的完整表述

## 1. 近代中国社会主要矛盾

1. **帝国主义和中华民族的矛盾。**（最主要）
2. **封建主义和人民大众的矛盾。**

**近代中国的两大历史任务：**
1. **争取民族独立、人民解放**；
2. **实现国家富强、人民富裕**。

## 2. 1952 年左右过渡时期的主要矛盾

**在打倒地主阶级和官僚资产阶级以后，中国内部的主要矛盾是工人阶级与民族资产阶级的矛盾。**

## 3. 中共八大关于社会主义制度建立后的主要矛盾

**人民对于经济文化迅速发展的需要同当前经济文化不能满足人民需要的状况之间的矛盾。**

**主要任务**：  
**集中力量发展生产力，全面开展社会主义建设，把我国尽快从落后的农业国变成先进的工业国。**

## 4. 十一届六中全会/改革开放后主要矛盾表述

**“人民日益增长的物质文化需要同落后的社会生产之间的矛盾。”**

- 强调的是生产力落后与人民需要增长之间的矛盾。

## 5. 党的十九大主要矛盾新表述

**“人民日益增长的美好生活需要和不平衡不充分的发展之间的矛盾。”**

**基本国情不变**：我国仍处于并将长期处于社会主义初级阶段。

# 二、三大改造：从什么转到什么

总起：三大改造的核心是把生产资料私有制改造为社会主义公有制，是中国由新民主主义社会进入社会主义社会的关键。

## 1. 农业改造

1. **从：农民个体所有制 / 个体小农经济。**
    
2. **到：社会主义集体所有制。**
    
3. 路径：互助组 → 初级农业生产合作社 → 高级农业生产合作社。
    

结尾：农业改造使个体农民逐步成为社会主义集体劳动者。

---

## 2. 手工业改造

1. **从：手工业者个体所有制 / 个体手工业经济。**
    
2. **到：社会主义集体所有制。**
    
3. 路径：手工业生产合作小组 → 手工业供销合作社 → 手工业生产合作社。
    

结尾：手工业改造使个体手工业者逐步纳入社会主义集体经济。

---

## 3. 资本主义工商业改造

1. **从：资本主义私人所有制。**
    
2. **到：社会主义全民所有制。**
    
3. 路径：国家资本主义 → 公私合营 → 全行业公私合营。
    
4. 方式：和平赎买。
    

结尾：资本主义工商业改造使民族资本家被改造成自食其力的劳动者。

---

## 4. 三大改造总括原话

这个最值得直接背：

1. **“把农民和手工业者以自己劳动为基础的私人所有制改造为合作社社员的集体所有制。”**
    
2. **“把以剥削工人阶级的剩余劳动为基础的资本主义私人所有制改造为全民所有制。”**
    

结尾：一句话概括就是：**个体私有制、资本主义私有制 → 社会主义公有制。**

# 三、过渡时期总路线

总起：过渡时期总路线是新中国从新民主主义向社会主义过渡的总纲。

1. 时间范围：  
    **从中华人民共和国成立，到社会主义改造基本完成。**
    
2. 原话要记：  
    **“在一个相当长的时期内，逐步实现国家的社会主义工业化，并逐步实现国家对农业、手工业和资本主义工商业的社会主义改造。”**
    
3. 简称：  
    **一化三改。**
    
4. “一化”：  
    **社会主义工业化。**
    
5. “三改”：  
    **对农业、手工业、资本主义工商业的社会主义改造。**
    

结尾：总路线的实质是使生产资料社会主义所有制成为国家和社会的经济基础。

# 四、1956 年社会主义改造完成的历史意义

总起：1956 年社会主义改造基本完成，是中国社会性质发生根本变化的标志。

1. **经济结构变化**：社会主义经济成分占绝对优势，社会主义公有制成为国家经济基础。
    
2. **制度变化**：以生产资料公有制为基础的社会主义经济制度建立起来。
    
3. **阶级关系变化**：官僚资产阶级被消灭，地主富农被改造，民族资本家被改造成自食其力的劳动者，工人阶级成为领导阶级，农民成为集体劳动者。
    
4. **社会性质变化**：中国进入社会主义社会。
    
5. **历史地位**：这是中国历史上最广泛、最深刻的社会变革。
    

结尾：但要注意，**中国进入了社会主义社会，不等于已经建成社会主义；仍处于不发达的社会主义初级阶段。**

# 五、几个常用定义

## 1. 新民主主义社会

总起：新民主主义社会是从新民主主义革命胜利到社会主义社会建立之间的过渡性社会。

1. 它不是资本主义社会。
    
2. 它也不是成熟社会主义社会。
    
3. 它包含国营经济、合作社经济、个体经济、私人资本主义经济、国家资本主义经济等多种经济成分。
    
4. 它的前途是社会主义。
    

结尾：所以新民主主义社会的关键词是：**过渡性、混合经济、多种阶级并存、前途社会主义。**

---

## 2. 社会主义初级阶段

总起：社会主义初级阶段是中国已经进入社会主义但生产力还不发达的历史阶段。

1. **已经是社会主义社会。**
    
2. **还处在不发达阶段。**
    
3. 基本国情是长期不变的。
    
4. 新时代仍然没有改变我国处于社会主义初级阶段的基本国情。
    

结尾：所以不能写成“中国还不是社会主义”，正确说法是：**已经进入社会主义，但仍处于社会主义初级阶段。**

---

## 3. “三大法宝”

总起：三大法宝是中国共产党领导新民主主义革命取得胜利的主要经验。

1. **统一战线。**
    
2. **武装斗争。**
    
3. **党的建设。**
    
4. 关系：统一战线和武装斗争是战胜敌人的两个基本武器，党的建设是掌握这两个武器的核心，是**根本保证**。



5. **近代中国社会主要矛盾：帝国主义和中华民族的矛盾、封建主义和人民大众的矛盾。**
    
6. **1952 年后：中国内部的主要矛盾是工人阶级与民族资产阶级的矛盾。**
    
7. **八大：人民对于经济文化迅速发展的需要同当前经济文化不能满足人民需要的状况之间的矛盾。**
    
8. **改革开放后：人民日益增长的物质文化需要同落后的社会生产之间的矛盾。**
    
9. **十九大：人民日益增长的美好生活需要和不平衡不充分的发展之间的矛盾。**
    
10. **过渡时期总路线：一化三改。**
    
11. **三大改造：个体私有制、资本主义私有制 → 社会主义公有制。**
    
12. **1956 年社会主义改造完成：中国进入社会主义社会，但仍处于社会主义初级阶段。**
