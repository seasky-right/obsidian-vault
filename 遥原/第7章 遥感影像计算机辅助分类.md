## 名词解释

- **监督分类**：在已知样区类别的信息下，根据已知的样本类别和类别的先验知识确定判别函数和判别准则，然后将未知类别的矢量观测值代入判定。
- **非监督分类**：事先不施加任何先验知识，仅凭地物在遥感影像上光谱特征的分布规律（自然聚类的特性），进行“盲目”的聚类。聚类结束后再通过目视判读或实地调查确定类别属性。
- **混淆矩阵**：（又称误差矩阵）对检验分类精度的样区内的所有像元，统计其分类图中的类别和实际类别之间的混淆程度，用表格的方式列出的用于定量比较计算机自动分类结果与真实地面参考数据之间对应与混淆程度的方阵数表，是计算总体精度、制图精度、用户精度以及Kappa系数的数学基础。
- **椒盐噪声**：指在基于像元的传统遥感自动分类专题图上，因算法仅孤立考虑单个像元的光谱特征而忽视空间邻域关系，导致大面积同类地物内部产生黑白交错、星星点点的孤立错分像元（或稀碎微小图斑）的现象。

## 课程内容

### 7.1 计算机分类概述

- **名词解释**
  - **计算机分类**：利用计算机技术来人工模拟人类的识别功能。其主要识别对象是遥感影像及各种变换之后的特征影像，目的是国土资源与环境的调查等。

- **知识点**
  - **分类的物理基础与实质**：分类的物理基础是地物波谱反射特性。同类地物在多维特征空间中形成一个从属于某种概率分布的集群，计算机分类的实质即模式识别。
  - **判别函数与规则**：判别函数是用来表示和鉴别某个特征矢量属于哪个类别的数学函数；判别规则是判断特征矢量具体归属某类的判断依据。

### 7.2 遥感影像变换与特征选择

- **名词解释**
  - **影像变换**：将原始影像通过一定的数学变换生成一组新的特征影像，使有效信息集中在少数几个特征影像上，从而参与后续的分类。
  - **主分量变换（PCA）**：一种建立在统计特征基础上的线性变换，它是所有正交变换中均方误差最小的最佳变换。其几何意义是把原始特征空间的特征轴旋转到平行于混合集群结构轴的方向上。
  - **穗帽变换（K-T变换）**：一种特殊的主成分分析。其转换系数是固定的且独立于单个影像，经过变换后可以提取并互相比较土壤的亮度、绿度以及湿度等特征。

- **知识点**
  - **影像变换的目的**：减少数据量、去除各波段间相关性，有助于提升分类效果。
  - **常用变换方法**：主分量变换、哈达玛变换、生物量指标变换（如NDVI计算）、比值变换以及穗帽变换等。
  - **特征选择方法**：分为定性的方法与定量的方法。其中定量方法包含相关系数法（相关性大则冗余大）、距离测度（如标准化距离法，距离越大说明两类地物的可分性越大）以及散布矩阵测度等。

- **主分量变换计算步骤**
  1. 计算多光谱影像的均值向量与协方差矩阵；
  2. 计算该矩阵的特征值和相应的特征向量；
  3. 将特征值按由大到小的次序进行排序；
  4. 选择前几个特征值对应的特征向量构造变换矩阵；
  5. 依据公式进行变换运算，得到的新特征影像即为结果。

### 7.3 基于像素的统计分类方法

- **名词解释**
  - **监督分类**：在已知样区类别的信息下，根据已知的样本类别和类别的先验知识确定判别函数和判别准则，然后将未知类别的矢量观测值代入判定。
  - **非监督分类**：事先不施加任何先验知识，仅凭地物在遥感影像上光谱特征的分布规律（自然聚类的特性），进行“盲目”的聚类。聚类结束后再通过目视判读或实地调查确定类别属性。

- **知识点**
  - **监督分类的方法类型**
    - **最大似然法**：基于概率判别函数和贝叶斯判别规则。假设同类地物在特征空间服从正态分布，准则为错分概率或风险最小。
    - **最小距离法**：基于距离判决函数分类，常用距离包括**马氏距离**（权系数为多维方差或协方差）、**欧氏距离**和**计程距离**。
    - ==**监督分类具体过程**==
		  1. 原始影像数据准备并进行特征选择；
		  2. 选择样区（要求样本具备准确性、代表性和统计性）；
		  3. 学习或训练，利用样本计算求出类别初始参数、设计分类器；
		  4. 依据判别函数对每个未知像素进行分类判别；
		  5. 形成分类编码影像并输出。

  - **非监督分类的方法类型**：**K-均值聚类法**、**ISODATA动态聚类分析**（迭代自组织数据分析算法）、**平行管道法聚类**、**系统聚类法**、**等混合距离法**。
	  - **K-均值聚类法步骤**
		  1. 任选K个初始聚类中心；
		  2. 逐个将样本按最小距离原则分配给各个聚类中心，形成类群；
		  3. 计算每类的新均值向量作为新的聚类中心；
		  4. 判断中心是否不变或变化小于阈值，否则重复迭代。
	  - **ISODATA算法步骤**
		  1. 初始化选择中心；
		  2. 按规则（如距离最小）对所有像元划分；
		  3. 重新计算集群均值和方差；
		  4. 按参数条件执行分裂与合并运算；
		  5. 满足迭代阈值则结束，否则循环；
		  6. 确认类别并作精度评定。
  - **监督分类的优缺点**：
	  - 优点：能有选择地决定类别、可控制并检查训练样本以避免严重错误；
	  - 缺点：具有主观性、样本选取和评估耗费人力时间、只能识别训练中定义的类别。
  - **非监督分类的优缺点**：
	  - 优点：不需要预先了解分类区域、人为误差少、量小的类别也能被区分；
	  - 缺点：结果不一定对应分析者想要的类别、难以控制产生的类别、不同影像间对比困难。

  - **分类后处理与精度评价**：采用人工干预或平滑处理（服从多数原则滤波），再基于**误差矩阵**评价其总体分类精度、用户精度、制图精度及Kappa系数。
  - **提高影像分类精度的方法**：包括分类前预处理（辐射与几何校正、纹理提取）、使用分类树与分层分类、混合分类（结合监督与非监督法）、多种信息复合（融合非遥感信息、高程信息等）及与GIS集成。

### 7.4 基于目标的分类方法

- **名词解释**
  - **目标（对象）**：依据同质性原则将光谱特性相近的像元合并而成的、有代表意义的多边形影像对象，可以理解为光谱信息类似像元的集合体。

- **知识点**
  - **基本思想**：土地覆盖反映自然属性，而土地利用反映社会属性。传统的传感器成像割裂了地物间的相关性，仅仅依靠像元的光谱特征不足以支撑土地利用信息提取，需转向以多边形对象为提取单位。

  - **对象的特征描述**：对象不仅包含颜色（光谱）、形状、纹理、层次结构，还包含复杂的类间特征（与相邻、子对象、父对象之间的关系）。

  - **基于目标分类的基本步骤**
	  1. 多尺度影像分割；
	  2. 确定分类体系和相应的分类器；
	  3. 利用成员函数对目标的特征进行模糊化；
	  4. 分类归属，最后进行精度评定。

- **多尺度分割两个原则** 
	 - 尽量以最大的可能分割尺度来区分不同的影像区域获得影像对象：在满足必要的精细的条件下尽可能使用大尺度。 
	 - 在满足必要的形状标准的前提下尽可能采用颜色标准：影像数据中最重要的信息是光谱信息，形状标准的权重太高会降低分割结果的质量。

  - **与传统统计分类的区别**：处理对象从像元变为多边形对象、呈现多层次、使用更多维特征、分类逻辑采用模糊理论且分类结果不同。

### 7.5 其他分类方法

- **知识点**
  - **人工智能与机器学习方法**：当前遥感分类正在引入深度学习（如卷积神经网络 CNNs、深度置信网 DBNs）。相比传统算法（如最大似然法），人工智能分类方法能自动学习提取多层次特征，在高分辨率下分类精度显著提升，但也存在依赖大规模高质量标注数据、决策依据具有“黑箱”特性以及计算资源消耗大等特点。

- **简答与思考题**
1. 从遥感影像上获取地物信息的方法主要有目视判读与计算机分类，比较它们的相同点与不同点？

2. 以监督法分类为例，叙述遥感影像计算机分类的过程。

3. 从获取信息的精度考虑，影响因素有哪些？

4. 评价不同分类方法的特点，并总结现有各类遥感影像软件分类模块的特点。

5. 在ISODATA算法聚类中，什么情况下分裂？什么情况下合并？什么情况结束迭代？如何确定最终类别？

6. 在我们学习过的内容里哪些分类不需要考虑地物在特征空间中的分布情况，简单说明理由？
	1. 最小距离法中的传统欧氏距离法（监督分类） 
		理由：该方法仅提取训练样本的“均值向量”作为类别中心。在判别时，只计算未知像元到各个类中心的绝对几何距离（欧氏距离）。它忽视了各类别数据内部的离散程度（方差）以及波谱段之间的相关性（协方差），无法准确描述地物集群在特征空间中具有“高矮胖瘦”和“倾斜延伸”的实际分布形态。 _(注：若需综合考虑分布，应采用引入协方差矩阵的马氏距离法。)_
	2. 平行管道法（非监督分类/监督分类均有应用）
		理由：仅提取各类样本在各波段上的最大值和最小值（极值），在特征空间中划定一个简单的多维矩形边界（管道）。只要像元落在边界内即可归类，不关心边界内部像元是集中在中心还是偏向一侧，即不考虑具体的统计分布。
	3. 最临近法（基于目标的分类）
		理由：对多尺度分割后的对象进行分类时，直接在特征空间中比较未知目标与定义样本之间的距离。与像元级的最小距离法类似，它属于单纯的距离度量，不建立概率分布模型。
	4. 基于知识的分类（基于目标的分类）
		理由：核心是构建专家规则库和逻辑条件（如设定 $\text{NDVI} < \sigma_0$）。通过成员函数将特征值直接映射为模糊隶属度，再进行逻辑“与/或”运算进行类赋值。这是一种显式的规则判断，不依赖统计学意义上的特征空间分布规律。
		
	概括而言：基于单纯几何距离度量的分类器，以及基于硬性/模糊逻辑规则的分类器，均不需要考虑分布情况。

7. 以最大似然法分类为例，给出遥感影像计算机分类的过程。如果请你将这个分类过程编程实现，你认为需要让用户操作的步骤有哪些？
	1. 最大似然法计算机分类的理论过程
		1. **遥感影像预处理**：首先对原始遥感影像进行辐射校正（消除传感器本身及大气附加影响）以减小椒盐噪声，进行几何精纠正以消除畸变并赋予正确的地理坐标，进行大气校正以恢复地表的真实反射率，从而为分类提供高质量的特征源数据。
		2. **确定分类体系与类别数量**：根据实际应用需求（如提取水体、植被、建筑等），明确待解译影像中包含的地物种类并确定具体的类别数量，确保分类目标清晰且具有科学代表性。
		3. **特征选择与信息降维**：定量评估各光谱波段间的信息量及相关性，筛选出最能拉开地物波谱反差的黄金波段组合，或通过主成分分析（PCA）等手段提取有效特征空间，消除波段间的信息冗余。
		4. **选取训练样区**：依据先验知识、目视判读或实地调查资料，在遥感影像上人工选取已知地物类别的典型、纯净区域作为监督分类的训练样本。
		5. **样区第一次评价（可计算性评估）**：对勾绘的样区进行初步质量把关，检验样本像元数量是否足够（通常需大于特征维数的10至100倍），以防因样本量过少导致后台程序在计算高维特征空间的协方差矩阵时出现奇异矩阵而崩溃。
		6. **计算统计特征参数**：基于通过初评的训练样区，提取样本像元在各特征波段上的灰度值，计算各个类别在特征空间中的统计参数。对于最大似然法而言，其核心是求取各类别的均值向量（决定点群在特征空间的中心位置）和协方差矩阵（决定点群的离散程度、长宽形状和延伸方向）。
		7. **样区第二次评价（分离度评估）**：利用计算出的统计参数，通过标准化距离、散布矩阵测度或JM距离等指标，定量评估各已知地物类别在特征空间中的可分性（分离度）。确保地物类别被清晰地分开、重叠度在允许范围内，否则需重新调整样本。
		8. **建立判决函数并执行分类**：最大似然法以同类地物在特征空间中服从多维正态分布为基本假设。算法利用贝叶斯判别规则建立概率密度判决函数，遍历整幅影像中的每一个未知像元，计算其属于各个已知类别的似然度（后验概率），最终将该像元划分到似然度最大的类别中。
		9. **执行分类后处理**：使用多数投票（Majority Filter）等邻域滤波算法，消除分类专题图结果中的“椒盐噪声”和孤立像元，合并微小图斑，提高斑块的空间连通性。
		10. **精度评定与反向反馈迭代**：引入独立于训练样本的真实地表数据作为检验样本，建立误差矩阵（混淆矩阵），计算总体精度、制图精度、用户精度和Kappa系数。此时引入迭代机制：若评估结果达标，则进入输出阶段；若不达标，则触发程序反馈接口，重新回到前置的样区选取、特征选择或参数设计环节进行修正计算，直至满意。
	2. 编程实现中需要让用户操作的步骤（人机交互设计）
		1. **步骤一：加载影像与配置预处理参数**。用户通过系统接口导入待解译的原始遥感影像，并在预处理面板中勾选或输入辐射定标系数、大气校正模型或几何控制点文件，点击下达预处理执行指令。
		2. **步骤二：新建分类体系与地物标签**。用户在软件工作区中创建所需的各类地物标签（如水体、林地、草地等），明确指定想要区分的地物类别数量，为后续样本指派做好准备。
		3. **步骤三：勾绘与编辑训练样本**。用户利用交互界面提供的多边形、矩形等矢量绘制工具，在影像图层上直接圈选典型地物斑块，或者直接导入现有的矢量样本文件，将这些图形区域指派给步骤二中建立的具体类别。
		4. **步骤四：查看样本评价报告并交互确认**。用户触发样本评估工具，在弹出的窗口或图表中查看系统计算出的样本量可计算性报告以及各类别间的分离度指标（如查看特征空间散点图、JM距离矩阵）。用户根据此处的定量数据在界面上点击确认进入下一步，或选择拒绝并返回步骤三重新修测样本。
		5. **步骤五：配置分类器参数并启动算法**。用户在工具面板中勾选“最大似然法”分类器，选择具体需要参与计算的影像波段或特征图层。确认无误后点击“执行”按钮，交由后台程序自动完成协方差运算与全图逐像元的概率判决。
		6. **步骤六：配置后处理参数并执行滤波**。在生成的初分类专题图层上，界面弹出滤波配置框，让用户手动输入滤波窗口大小（如 3×3 或 5×5 像素），点击执行以平滑去噪。
		7. **步骤七：导入验证样本与精度评价**。用户在界面中导入独立的真实地表解译矢量或点数据作为检验样本，触发系统运行并在线查看生成的混淆矩阵、总体精度及Kappa系数报告。
		8. **步骤八：结果满意度交互反馈与结果导出**。根据精度验证报告，若用户对结果不满意，点击程序提供的“不满意/重入循环”接口进行动态反馈，系统保留当前分类体系并自动激活样区编辑工具，允许用户重新调整样区和参数；若用户对结果满意，则点击导出按钮，将最终的专题图保存为栅格（如TIFF）或矢量（如Shapefile）格式完成输出。
