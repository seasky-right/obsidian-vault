## 名词解释

- **辐射校正**：指消除或改正遥感影像成像过程中附加在传感器输出的辐射能量中的各种噪声的过程。
- **传感器绝对辐射定标**：通常通过计算每个波段的增益（Gain）和偏置（Offset）等系数，来实现利用原始的数字量化（DN）值标定绝对辐射能量值的过程。
- **传感器相对辐射定标**：实现传感器探测元件归一化的过程，其目的是消除传感器各个探测元件响应度不一致性引起的条带噪声等。
- **场地定标**：指遥感器处于正常运行条件下，选择具有特定特征的辐射定标场地，通过地面同步测量对遥感器进行在轨辐射定标。
- **辐射交叉定标**：以定标精度较高的遥感卫星/传感器为标准参考，来对待定标目标传感器进行辐射标定的方法。
- **大气校正**：消除成像过程中大气分子、气溶胶和云粒子等吸收与散射影响，将传感器的辐射亮度或表观反射率转换为地表实际反射率的处理过程。
- **多光谱影像变换**：将原始影像通过一定的数学变换生成一组新的特征影像，使信息高度集中在少数几个特征影像上以实现去相关和降维，主要用于提取特定特征和辅助分类。
- **影像融合**：对多传感器数据和其他信息进行运算处理，将空间或时间上冗余或互补的多源数据结合，生成具有新的空间、波谱、时间特征的高质量合成影像。
## 课程内容
### 5.1 遥感影像的辐射校正

- **辐射误差的来源**：
	1. 传感器本身的性能缺陷引起的误差
	2. 地形影响和光照条件变化引起的失真
	3. 大气的散射和吸收作用引起的衰减。
- **辐射校正的主要内容**：
	1. 传感器辐射定标（绝对定标、探元间相对定标）
	2. 大气校正
	3. 地形及其他因素（如太阳高度角等）校正。
- **入瞳辐射能量组成**：传感器接收的总电磁波能量包括：①太阳经大气衰减照射地面反射后再经大气衰减进入传感器的能量；②地面自身发射辐射经大气后进入传感器的能量；③大气自身的散射、反射和发射的路径辐射能量。
- **传感器绝对定标类型**：
  - **实验室定标**：发射前在实验室进行，是精度较高的初始定标，包含光谱定标与辐射定标。
  - **机上和星上定标**：实时获取波段漂移和辐射响应变化，参考标准分为内部（积分球、定标光源）和外部（太阳、月亮、大气吸收线等）。
  - **场地定标**：反映入轨实际情况的校正，主要有反射率基法、辐亮度基法、辐照度基法三种方法。
	  - **特点**：
		  - 以大面积地表均匀地物作为定标源
		  - 多通道、动态、大范围定标
		  - 考虑大气传输环境的影响
	  - **定标场地要求**：
		  - 面积大+地物均匀+有利的大气环境
	  - **技术流程**：
		  1. 获取空中、地面及大气环境同步观测数据。
		  2. 计算大气气溶胶参数及大气中水和臭氧的含量。
		  3. 采集、分析定标场大面积均匀地物的光谱反射率数据。
		  4. 获取遥感器位置及成像时间，借助大气传输模型计算传感器入瞳辐射值。
		  5. 匹配输出的数字量化值，计算定标系数并估算误差。
- **交叉辐射定标条件**：为保证定标精度，必须尽量满足**视场条件**、**时相条件**（同步或准同步过境）、**几何条件**与**光谱条件**一致。
- **相对定标（探元间去条带）方法**：常用方法有**矩匹配法**、**均衡补偿法**、直**方图调整法**、主成分分析法及滤波法等。
- **大气对太阳辐射的影响机理**：包含太阳直射和反射衰减、天空光、程辐射、反射光散射和多次反射。
- **大气校正方法分类**：基于大气辐射传输模型法（如6S模型、MODTRAN等）、基于地面线性回归模型法、基于影像特征的相对校正法（如暗目标法、植被指数）、完全基于影像大气订正法等。
- **其他因素校正**：包括太阳高度角改正（标准化到垂直照射）、地形坡度改正（通过比值影像部分消除阴阳坡反差）、日地距离校正等。
- **6S大气辐射传输模型流程**：
  1. 输入几何条件、大气模式、气溶胶模式、光学厚度、波段信息及地表反射率五类参数。
  2. 模拟太阳辐射经过大气到达地表，再经地表反射透过大气的传输全过程。
  3. 模型解算出各波段对应的大气校正系数（如 $x_a, x_b, x_c$）。
  4. 将原始影像进行定标后，应用校正参数进行公式换算，输出真实的地表反射率影像。

### 5.2 多光谱影像运算与变换

- **多光谱影像变换**：将原始影像通过一定的数学变换生成一组新的特征影像，使信息高度集中在少数几个特征影像上以实现去相关和降维，主要用于提取特定特征和辅助分类。
- **主分量变换（PCA / K-L变换）**：一种在统计特征基础上的最佳正交线性变换，其几何意义是将原始特征空间的坐标轴旋转至平行于数据集群分布的结构轴方向上，使得变换后的各特征影像互不相关且均方误差最小。
- **穗帽变换（K-T变换）**：一种针对农业和植被应用设计的特殊线性正交变换。其转换系数是固定的并独立于单个影像，能将各波段的反射率重新投影到反映土壤“亮度”、植被“绿度”和含水量的“湿度”等具有明确物理意义的特征平面上。

 - **主分量变换（PCA）计算步骤**：
  1. ==计算原始多光谱影像所有波段的均值向量$M$和协方差矩阵$C$。==
  2. 求解该协方差矩阵的特征值及对应的特征向量。
  3. 将特征值按由大到小的次序排列。
  4. 选择前几个最大特征值对应的特征向量构造正交变换矩阵。
  5. 将原始像元向量代入矩阵方程进行线性变换，生成包含主成分信息的融合后影像。
- **波段间基本数学运算**：
  - **除法（比值）运算**：能有效压抑因地形坡度和方向引起的辐射量变化，消除部分地形起伏的阴影影响，同时能够极大增强植被、水体、土壤之间的辐射反差。
  - **混合运算（植被指数）**：如归一化植被指数（NDVI）、大气阻抗植被指数（ARVI）等，可以部分校正大气程辐射影响并突出植被生长状态。
- **主分量变换（PCA）的性质**：
  - 变换后矩阵的协方差矩阵对角化，各主成分完全不相关。
  - 信息高度集中在第一主分量（PC1），例如MSS影像的PC1能包含原始数据90%以上的信息，后续分量信息递减且噪声增加。
- **特征选择方法**：
  - **定性方法**：依据传感器各波段的物理特点和特征影像的目视效果选择。
  - **定量方法**：包括相关系数法（相关性过高的冗余波段可剔除其一）、距离测度（如标准化距离，距离越大类别可分性越高）以及散布矩阵测度等。

### 5.3 影像融合

- **影像融合**：对多传感器数据和其他信息进行运算处理，将空间或时间上冗余或互补的多源数据结合，生成具有新的空间、波谱、时间特征的高质量合成影像。
- **层次**：
	- **像素级融合**：直接对多源原始影像像元进行的底层数据融合，旨在增加影像细节、改善视觉和处理效果。
	- **特征级融合**：先利用算法从各类数据中提取目标特征（如边缘、纹理、形状），然后对特征空间信息进行综合分析和叠加处理。
	- **决策级融合**：基于影像理解和特征识别的高层次融合，综合不同传感器的分类结论为最终决策服务。

- **影像融合的目的**：提高多光谱影像的空间分辨率、改善影像配准精度、增强地物特征、提升分类精度、修补影像缺陷，实现信息量“1+1>2”的增益效果。
- **融合的关键因素**：精确的空间几何配准；融合模型的优化（兼顾地学规律及各种数据源的优缺点）；最佳融合波段和算法的选择。
- **常用融合方法与特点**：
  - **基于IHS变换的融合**：可保留全色影像的高分辨率细节并维持多光谱色调，但易引起一定程度的光谱退化，且一次只能针对三个波段操作。
	  - **融合流程**：
	  1. 对多光谱影像和高分辨率全色影像进行精确的几何配准，并将多光谱影像重采样至相同分辨率。
	  2. 将多光谱影像由RGB色彩空间转换至IHS（亮度、色调、饱和度）空间。
	  3. 提取出IHS空间中的亮度分量（I），并将其与全色影像进行直方图匹配。
	  4. 利用直方图匹配后的全色影像替代原多光谱的亮度分量（I）。
	  5. 进行IHS空间至RGB空间的逆变换，输出既具高空间分辨率又保留原色彩信息的融合影像。
  - **基于主分量变换的融合**：将高分辨率全色影像与多光谱PC1进行直方图匹配和替换，能保留高频细节并应用至多于三个波段，但在光谱和空间分辨率上会发生一定折中变形，有时不利于定量反演。
  - 其他方法还包括加权融合、比值变换、乘积变换、高通滤波及小波变换融合等。
- **融合结果评价**：包含定性目视评价以及定量评价（如基于熵的信息量评估、基于梯度评价清晰度、基于离散度评价影像逼真度）。
