## 名词解释

- **几何变形**：影像上像元在影像坐标系中的坐标与其在地图坐标系等参考坐标系统中的对应坐标之间的差异。
- **静态误差与动态误差**：静态误差指传感器相对地球静止时具有的变形误差；动态误差由于地球旋转或平台运动等动态因素造成。
- **灰度值重采样 (Resampling)**：通过反变换计算出的原始影像坐标通常为非整数，需要将该点邻近整数点位上的亮度值贡献累积起来，赋予新像素点的过程。
- **影像镶嵌 (Image Mosaicking)**：将同一地区包含不同文件（不同轨道或不同时间）的影像拼接在一起，形成完整研究区域影像。
- **影像裁剪 (Image Cropping)**：根据研究区域大小、规则或不规则边界截取影像的特定部分。
## 课程内容
### 4.1 遥感传感器的构像方程

- **名词解释**
  - **共线方程**：描述像点、对应的地物点和传感器投影中心三者位于同一条直线上的数学关系方程。主要用于计算影像与地面之间的坐标变换（正算与反算）。
	  - **公式**（简写）：
	  
		  $\begin{bmatrix} X \\ Y \\ Z \end{bmatrix}_P = \begin{bmatrix} X \\ Y \\ Z \end{bmatrix}_{S_t} + \lambda_P A_t R_\theta \begin{bmatrix} x \\ y \\ -f \end{bmatrix}$
	  
		  $(X) = a_{11}(X_P - X_S) + a_{21}(Y_P - Y_S) + a_{31}(Z_P - Z_S)$
		  $(Y) = a_{12}(X_P - X_S) + a_{22}(Y_P - Y_S) + a_{32}(Z_P - Z_S)$
		  $(Z) = a_{13}(X_P - X_S) + a_{23}(Y_P - Y_S) + a_{33}(Z_P - Z_S)$$$x = -f \frac{(X)}{(Z)}$$$$y = -f \frac{(Y)}{(Z)}$$
	  - **正算公式**：已知地面点三维坐标：$P(X, Y, Z)$，求像点坐标
	  - **反算公式**：已知像点坐标$(x, y)$和该点处的地面高程$Z$，求地面点坐标
	  - **不同传感器的方程特征对比**：
		  - **框幅式（面阵相机）**：整幅影像所有像素**共享同一组**固定的外方位元素。
		  - **推扫式（线阵卫星）**：逐行成像，飞行方向像坐标恒定（通常 $\mathbf{x=0}$），**每一行影像都有独立的一组外方位元素**，它们是时间 $t$ 的动态函数。
		  - **摆扫式（光机扫描）**：瞬时成像点永远在焦平面中心（$\mathbf{x=0, y=0}$），外方位角元素中要叠加扫描镜的瞬时摆角 $\theta(t)$。

  - **有理函数模型 (Rational Function Model, RFM)**：一种与具体传感器物理构造无关的通用模型。它将像点坐标表示为以相应地面点空间坐标（经平移和缩放标准化后）为自变量的多项式比值。
	  - **公式**：$$r = \frac{P_1(X, Y, Z)}{P_2(X, Y, Z)}, \quad c = \frac{P_3(X, Y, Z)}{P_4(X, Y, Z)}$$
	  - **系数数量**：固定为 **78** 个（或 **80** 个）。

  - **多项式模型**：回避成像的空间几何过程，直接对影像变形本身进行数学模拟，将其看作是平移、缩放、旋转、偏扭及弯曲等基本变形的综合作用。
	  - **公式**：$$x = a_0 + a_1X + a_2Y + \dots$$$$y = b_0 + b_1X + b_2Y + \dots$$
	  （正算反算“双向平等”）
	  - **所需（最少）控制点数量**：$N = \frac{(n+1)(n+2)}{2}$（实际生产应远大于此）
	  - **系数数量**：$(n+1)(n+2)$ （1阶->6个 2阶->12个 3阶->20个）

| **几何校正模型**     | **是否需要控制点(GCP)** | **是否需要 DEM (高程)** | **是否需要厂商提供辅助数据**       | **适用场景与特点**                |
| -------------- | ---------------- | ----------------- | ---------------------- | -------------------------- |
| **二维多项式**      | **必须（强依赖）**      | 不需要               | 不需要任何厂商数据              | 适用于地形平坦、小范围、低分辨率影像。        |
| **有理函数 (RFM)** | 选配（用于精化）         | **必须**            | **必须提供 RPC 参数文件**      | 高分辨率卫星正射纠正的行业标准，速度极快。      |
| **严格共线方程**     | 选配（用于平差）         | **必须**            | **必须提供内方位元素和线阵逐行姿态星历** | 理论上最严密、精度最高，但数据流庞大、计算极其复杂。 |

- **知识点**
  - **构像方程涉及的主要坐标系**：**物方坐标系 (O-XYZ)**、**传感器坐标系 (S-UVW)**、**影像像点坐标系 (o-xyf)**、本体坐标系、轨道坐标系、空间固定惯性坐标系 (J2000)、以及**2000中国国家大地坐标系 (CGCS2000)**。

  - **各类传感器构像方程特点**
    - **中心投影**：常规框幅式摄影应用，符合基础共线方程。
    - **线阵推扫式传感器**：影像逐行扫描，其构像方程在飞行方向上的像面坐标恒为常数（如垂直对地成像时 $x=0$）。
    - **摆扫式传感器**：传感器沿旁向扫描，扫描角随时间变化，同样通过旋转矩阵归化至共线方程。
    - **侧视雷达 (SAR)**：属于主动式传感器，具有**斜距投影**的性质，依赖于雷达波往返时间计算天线至地物点的空间距离。

  - **二维多项式模型的优缺点**
    - 优点：模型简单直观。
    - 缺点：不能真实描述影像形成过程中的误差来源和地形起伏引起的变形。
    - 适用范围：仅限于变形小、垂直视角、小范围且地面平坦的影像。

### 4.2 遥感影像的几何变形

- **名词解释**
  - **几何变形**：影像上像元在影像坐标系中的坐标与其在地图坐标系等参考坐标系统中的对应坐标之间的差异。
  - **静态误差与动态误差**：静态误差指传感器相对地球静止时具有的变形误差；动态误差由于地球旋转或平台运动等动态因素造成。
  - **内部误差与外部误差**：内部误差由传感器自身性能指标偏移标称数值造成；外部变形则是传感器正常工作下由于外部因素（如地形、大气）造成的。
  - **高分影像震颤 (平台颤振)**：卫星在轨运行期间，因姿态调整、指向控制、运动部件周期性运动等因素引发的扰动，使得星体产生幅值较小的微振动，导致振动像移。

- **知识点（影响变形误差的因素）**
  - **传感器成像方式**：全景投影变形、斜距投影变形（雷达影像）。
  - **传感器外方位元素变化**：外方位元素（高度/位置变化和姿态角绕x、y方向旋转及偏航）偏离标准位置带来的综合变形。
  - **地形起伏引起的投影差**
    - 中心投影：沿像点与像底点（影像中心）的连线，呈全向辐射状向外背离中心位移。
    - 推扫式：投影差**仅发生在扫描（y）方向**，随旁向距离 $y$ 的增加而**线性增大**。
    - 摆扫式：主要发生在摆扫方向（旁向），并且与扫描全景畸变相互叠加（中间宽、两边窄）。离中心线越远（瞬时扫描角 $\theta$ 越大），倾斜角度越大，地形起伏引起的投影差和全景几何变形越剧烈。
    - 侧视雷达：与光学中心投影相反，高程高于基准面的地面目标点向靠近传感器（天线航迹）的方向（即近距端）位移。
  - **地球曲率影响**：类似系统性的地形起伏。
  - **大气折射影响**：导致电磁波传播路径变弯曲而引起像点位移。
  - **地球自转影响**：针对多中心投影扫描成像，导致各扫描线投影依次向西平移，影像发生扭曲。
  - **平台震颤特性**：具有周期性、微小性、难测性和固有性，主要体现在导致影像模糊（清晰度下降）与内部几何变形。

### 4.3 遥感影像的几何处理

- **名词解释**
  - **粗纠正处理**：接收部门根据遥感平台、地球和传感器预知参数进行的初步系统误差改正，处理后仍包含较大残差（不能直接使用）。
  - **精纠正处理 (几何校正)**：利用地面控制点等信息消除残余的几何变形，生成符合某种地图投影或图形表达要求的新影像。
  - **灰度值重采样 (Resampling)**：通过反变换计算出的原始影像坐标通常为非整数，需要将该点邻近整数点位上的亮度值贡献累积起来，赋予新像素点的过程。

- **技术流程：遥感影像几何精纠正过程**
  1. **模型选择**：根据区域与传感器类型选择（多项式、共线方程、有理函数等）。
  2. **参数计算或精化**
     - **多项式法**：通过均匀分布、易判读、精度高的地面控制点(GCP)建立误差方程，采用最小二乘法进行曲面拟合求取系数。
	     - **适用传感器：** **所有传感器均适用（传感器无关）**。最常用于传统的低/中分辨率扫描仪、航空框幅式相机或雷达影像的简单配准。
		 - **使用条件：
			- **地形要求：** 仅适用于**地形相对平坦**、高程起伏较小的区域。
		    - **形变要求：** 影像几何变形相对简单、幅面较小（窄视场）。
		    - **数据要求：** 必须有**足够数量且分布均匀**的高精度地面控制点 (GCP) 建立法方程。
		    - **局限性：** 属于二维纯数学经验拟合，**无法消除因高程起伏引起的局部投影差**（不使用 DEM）。
		- **纠正内容**：
			- **一次项纠正**：改正影像因平移、旋转、比例尺变化等引起的线性变形；
			- **二次项纠正**：在改正一次项各种变形的基础上，改正二次非线性变形；
			- **三次项纠正**：改正更高次的非线性变形。
		- **对控制点的要求**：
			1. 在影像上为明显的地物点，易于判读；
			2. 在影像上均匀分布；
			3. 数量足够；
			4. 精度要符合要求。
     - **共线方程精化**：利用POS系统直接获取初始参数，或引入“伪观测值”防止强相关性不稳定，通过地面控制点做单像空间后方交会解算外方位元素。
		- **适用传感器：** **框幅式相机**（面阵）、**线阵推扫式传感器**（如SPOT、Landsat 8、资源系列）。
		 - **使用条件：** 
			- **地形要求：** 适用于地形起伏剧烈（如高山地、峡谷）的复杂区域。
		    - **精度要求：** 适用于需要进行高精度正射纠正的生产任务。
		    - **数据要求：** 必须有**高精度数字高程模型 (DEM)**，必须有传感器**内方位元素**以及星载 POS 系统提供的**初始外方位元素（星历与姿态数据）**。辅以少量地面控制点 (GCP) 进行单像空间后方交会，以消除初始姿态的系统误差。
     - **有理函数 (RPC) 解算**：用严格模型建立立体空间格网作为虚拟控制点，再利用最小二乘法求解RPC，并用检查点评定精度。
		- **适用传感器：** **几乎所有传感器，尤其占据垄断地位的是新型高分辨率商业/军用遥感卫星**（如 WorldView、GeoEye、高分系列、吉林一号等线阵推扫式卫星）。
		- **使用条件：** 
			- **厂商限制：** 适用于**厂商不公开相机严格物理参数**的情况。模型由厂商在基地用严密模型和虚拟控制点格网预先拟合生成。
		    - **数据要求：** 强依赖于厂商随影像提供的 **RPC 辅助参数文件** 和 **DEM 数据**。
		    - **控制点要求：** 依靠自带参数即可实现**无控制点**的快速正射纠正；若想进一步消除平移等残余系统误差，只需引入极少数（如1~3个）高精度 GCP 进行参数精化（即 RPC 区域网平差）。
		    - **局限性：** 属于数学拟合（“黑盒模型”），**严禁外推**，即在厂商设定的高程或平面范围之外进行计算会产生巨大误差。
     - **像方几何变换系数解算**：规避外方位元素求解过程中的奇异矩阵和不收敛问题，直接求解像方变形。
		- **适用传感器：** 视场角极窄的**线阵推扫式卫星**或**高频摆扫式传感器**。
		- **使用条件：** 
			- **数学解算困境：** 当采用严格共线方程精化时，由于卫星轨道极高、视场角极小，导致某些**外方位元素之间存在极强的线性相关性**（例如位置变化与姿态角变化在像面上产生的变形极其相似，如 $X_S$ 平移和绕 $y$ 轴的俯仰角变化）。
		    - **适用场景：** 当强相关性导致最小二乘法迭代解算过程中出现**法方程矩阵奇异（病态）或不收敛**时。
		    - **处理策略：** 放弃在物方空间解算带有物理意义的外方位元素，直接在“影像空间（像方）”层面设置附加参数模型，利用控制点求解能吸收集体变形的综合系数，从而绕开病态矩阵问题。
  3. **像素坐标变换（影像边界确定）**：利用纠正变换函数，计算原始影像各角点在地图坐标下的范围，计算生成新影像矩阵的行列数(M, N)。
  4. **像素亮度值重采样（间接法）**：依据确定的输出影像格网，反算其在原始影像中的浮点坐标，并进行重采样获取灰度。
     - **最邻近像元采样法**：直接将距离浮点坐标 $(x, y)$ 最近的整数像素位置的灰度值赋给该点。（运算快，保真，但有几何锯齿）。
     - **双线性内插法**：利用待求点周围的 **4** 个相邻像素，在 $x$ 和 $y$ 方向上分别进行线性内插。距离待求点越近的像素，其权重越大。（平滑，抑制噪声，但会丢失边缘锐度）。
     - **双三次卷积重采样**：利用待求点周围的 **16** 个相邻像素的灰度值进行三次多项式拟合计算。其核心是利用以下三次卷积权函数 $S(x)$ 来计算各点的权重。（平滑且具有边缘锐化效果，计算量最大）。
  5. **结果精度评价**：通过评价指标（均值、中误差、均方根误差RMSE、长度/角度变形精度、圆点误差CE）检验最终误差是否在限差范围内。

### 4.4 影像间的自动配准和数字镶嵌

- **名词解释**
  - **影像镶嵌 (Image Mosaicking)**：将同一地区包含不同文件（不同轨道或不同时间）的影像拼接在一起，形成完整研究区域影像。
  - **影像裁剪 (Image Cropping)**：根据研究区域大小、规则或不规则边界截取影像的特定部分。

- **知识点与技术流程**
  - **影像间的自动配准**
    - 分类：绝对配准和相对配准（同一传感器或不同传感器）。
    - 流程：关键是利用影像匹配方法获取**同名点**，随后运用多项式做整体配准，或基于小面元微分纠正进行自动配准。
  - **影像镶嵌的关键问题与流程**
    - 关键问题：解决几何畸变、色调不一致、接缝突兀等问题。
    - 流程环节：
      1. 影像的几何纠正；
      2. 搜索最佳镶嵌拼接边；
      3. 亮度和反差调整：对重叠区计算平均亮度，改变整幅影像基色，利用灰度极值做反差拉伸以统一色调；
      4. 平滑边界线：通过距离权重计算（如羽化处理 Feathering Logic）实现平滑过渡，抹除拼接缝。

## 随堂与课后练习题汇总

#### 1. 为什么要进行影像的几何纠正？影像几何纠正的内容是什么？影像几何纠正模型有哪些？影响影像几何纠正精度的因素有哪些？如何提高影像几何纠正精度？

- **纠正原因**：遥感影像在获取过程中受传感器构造、平台运动状态变化（如高度、姿态改变）、地球自转与曲率、地形起伏及大气折射等多种因素影响，产生了几何变形（畸变）。导致影像上像元的坐标与真实的地图坐标不一致，无法直接用于长度面积测量、空间分析、图层叠加或制作正射影像图。
- **纠正内容**：包括**坐标空间变换**（利用纠正模型将原始影像坐标映射到标准地理坐标系或反算）和**灰度重采样**（为新网格中的浮点坐标重新赋予亮度值）两个核心部分。可分为粗纠正（消除系统误差）和精纠正（消除随机与残余误差）。
- **纠正模型**：多项式模型、共线方程模型（严格物理模型）、有理函数模型（RPC模型）、小面元微分纠正模型等。
- **影响精度的因素**：地面控制点（GCP）的数量、分布与量测精度；纠正模型的选择；地形起伏程度；原始影像的分辨率与变形复杂程度；重采样算法的选择。
- **提高精度的方法**：
  1. 增加控制点数量，并确保控制点均匀分布在影像全域及边缘；
  2. 优先选用严格物理模型（如共线方程）或高精度有理函数模型；
  3. 利用高精度数字高程模型（DEM）消除地形引起的投影差；
  4. 采用高精度GPS/IMU辅助定位定姿数据；
  5. 对控制点及检查点进行严密筛选，剔除粗差点。

#### 2. 几何纠正需要哪些数据？哪些数据是已知的、精确的？哪些是已知但不精确的？哪些是未知的？

- **需要的数据**：带有几何变形的原始遥感影像、参考地图或高精度正射影像、地面高程模型（DEM）、地面控制点（GCP）。
- **已知的、精确的**：实地量测或从参考高精度底图中获取的**地面控制点（GCP）地理坐标**；选用的参考坐标系标准。
- **已知但不精确的**：**原始影像上的像点坐标**（因存在畸变而不精确）；随星附带的传感器初始姿态/星历数据或初始RPC参数。
- **未知的**：纠正模型的**待定系数**（如多项式的各项系数、共线方程解算后的外方位元素）；重采样后新影像矩阵中**每个像元对应的真实灰度值**。

#### 3. 对于TM影像，由于是摆扫式传感器，其构像方程中 $x=?$, $y=?$

- **答**：TM传感器属于光机摆扫式（Whiskbroom）传感器。探测器固定在光学系统的焦平面中心（光轴上），通过扫描镜的横向摆动实现对地扫描成像。
- 因此，在其**瞬时构像方程**（传感器本身坐标系）中，成像瞬间像点的坐标固定为：**$x = 0$ 且 $y = 0$**。其扫描范围的拓展不是通过像面上的不同位置实现的，而是通过不断改变扫描镜的姿态角（外方位元素 $\omega(t)$ 随时间变化）来实现的。

#### 4. 思考：有理函数模型的不足是什么？

- **答**：
  - **物理意义不明确**：属于纯数学模型，无法直接获取传感器姿态参数，不利于误差溯源。
  - **过度参数化**：高阶RPC易产生过度拟合，导致无控制点区域出现难以预料的非线性抖动。
  - **对控制点依赖性强**：在缺少实际地面控制点的情况下，其绝对定位精度完全依赖于卫星提供的初始RPC参数，而初始RPC在不同地域可能存在系统误差。
  - **地形相关性退化**：在无地形起伏的平坦区域，解算高阶RPC可能导致法方程奇异，模型失效。

#### 5. 粗纠正处理对传感器内部畸变的改正很有效，但是处理后仍有很大的残差，用户不能直接使用。原因是什么？为何要做精纠正处理？怎么知道有形变？纠正的具体方法有哪些？

- **原因**：粗纠正仅利用了卫星星历、姿态数据等预知的系统参数进行改正，未考虑**随机误差**以及获取的**姿态/星历数据本身存在的残余误差**。更重要的是，它没有利用地面控制点（GCP），无法消除因外界因素导致的复杂非线性畸变和大地定位误差。
- **为何精纠正**：为了消除粗纠正后的残余误差，将影像精确配准到标准地图投影坐标系中，使其能与其它地理空间信息精确“对齐叠合”，满足定量遥感和地理信息系统应用的需求。
- **判断有形变的方法**：通过将影像配准到高精度基准参考图（如数字正射影像图DOM）上，观察同名地物点之间存在的错位距离，或在进行影像镶嵌时发现接边错位。
- **纠正的具体方法**：共线方程精化法（解算外方位元素）、多项式整体纠正法、有理函数模型（RPC）区域网平差法等，辅以数字高程模型（DEM）进行正射纠正。

#### 6. 在几何纠正过程中，关键是哪个环节？

- **建立适配的几何变换数学模型**：几何纠正的核心是构建原始畸变影像坐标（像方）与地面地图投影坐标（物方）之间的空间几何映射机制。必须根据传感器的构像物理特性、原始形变的复杂程度以及处理区域的地形起伏条件，选择并建立正确的数学函数关系模型，这是确保纠正精度与拟合能力的前提底座。
- **获取高质量与合理空间分布的地面控制点（GCP）**：控制点坐标是解算与精化几何变换模型中未知参数的物理依据。控制点的获取关键在于：数量必须达到模型平差解算的多余观测要求以抑制偶然误差，自身位置必须具备高精度的地理空间坐标，且在整幅影像全域内必须呈现出网格状的均匀分布以防止边缘盲区产生外推残差发散。
- **执行高保真的像元灰度值重采样**：在完成新旧图像网格的空间坐标几何转换后，必须利用灰度内插算法对新网格中的像元进行亮度值重新赋予。关键在于根据实际需求选择适配的内插算法，在保证辐射能量准确定标的同时，最大限度地避免产生微观几何错位、锯齿或边缘模糊，从而最终完成高精度的影像重建。

#### 7. 重采样后的精度评定与模型确定时参数的精度评定有什么区别？

  - **模型参数精度评定**：利用参与建模的**地面控制点 (GCP)** 的改正后残差进行内符合精度分析。这只反映了模型对这些已知控制点的拟合程度，不代表未参与计算区域的实际精度。
  - **重采样后的精度评定**：利用**未参与建模的独立检查点 (Check Points)** 进行外符合精度评定（计算RMSE等）。它通过计算模型推算出的坐标与真实坐标的差值，真实地反映了最终纠正影像的实际几何定位误差，是更客观、更可靠的精度评价指标。

#### 8. 为什么共线方程纠正和多项式纠正的结果差别如此之大？原因是什么？还有哪些纠正方法，不同传感器纠正所用模型有什么区别？本节内容处理思想与传统获取空间信息的方法有什么区别？

- **原因**：
  - **共线方程**：基于传感器的物理成像机理，能精确模拟推扫过程中的姿态与位置变化，有效消除因长焦距、地形起伏引起的非线性投影差，适合高分辨率卫星影像。
  - **多项式纠正**：单纯的数学曲面拟合，无法顾及地形起伏引起的局部高差投影差。在地面不平坦或传感器视角大时，大量局部畸变会被“均摊”或拟合错误，导致结果存在较大残差。
- **其他纠正方法及传感器区别**：
  - 光学框幅式：适用共线方程、直接线性变换(DLT)。
  - 高分辨率推扫式卫星：适用严格几何模型（共线方程）、有理函数模型(RPC)。
  - SAR雷达影像：适用距离-多普勒（Range-Doppler）模型、基于轨道参数的几何构像方程。
- **与传统获取空间信息方法的区别**：传统测绘直接在实地或航片上通过单点量测获取离散坐标点；而本节内容强调采用**整体精密解算**、**逐像素密集点变换**的数字化、自动化方式，一次性生成带有正确地理编码且灰度值连续的完整数字影像。

#### 9. 写出框幅式、推扫式、摆扫式传感器的构像方程，指出其中各个参数的含义。（作业题）

- **框幅式（中心投影）**：
  $$x = -f \frac{a_1(X - X_S) + b_1(Y - Y_S) + c_1(Z - Z_S)}{a_3(X - X_S) + b_3(Y - Y_S) + c_3(Z - Z_S)}$$
  $$y = -f \frac{a_2(X - X_S) + b_2(Y - Y_S) + c_2(Z - Z_S)}{a_3(X - X_S) + b_3(Y - Y_S) + c_3(Z - Z_S)}$$
  - $f$：焦距。$(x,y)$与$(X,Y,Z)$分别为像点与地物坐标。$a_i,b_i,c_i$为外方位角元素构成的方向余弦。

- **推扫式（线中心投影）**：
  方程为 $x = 0$ (扫描线上)，y方程与框幅式相同。区别在于每一整行扫描线对应一组独立的外方位元素 $X_S(t), Y_S(t), Z_S(t)$ 和姿态矩阵。

- **摆扫式**：
  其构像本质与框幅式方程一致，但在瞬间像点坐标只能处于探测器中心，即 **$x = 0, y = 0$**。取而代之的是，旋转矩阵需加入随时间变化的扫描镜转角 $\omega(t)$，实现不同方向的地面点观测。

#### 10. 结合实习，以多项式纠正为例，叙述遥感影像精纠正过程。影响遥感影像几何精度的因素有哪些？如何提高影像纠正精度？（作业题）

- **多项式纠正过程**：
  1. **导入数据**：打开待纠正遥感影像和高精度参考图。
  2. **选取控制点 (GCP)**：在影像和参考图上精确选择清晰不易位的地物同名点（如道路交叉口）。通常二阶多项式至少选6个，操作时会选十几个并尽量让点分布均匀。
  3. **模型计算**：输入控制点坐标，运行多项式最小二乘平差，剔除残差过大的粗差点，反复迭代直至中误差达标。
  4. **重采样输出**：设定输出影像的投影信息和像元分辨率。选择重采样方法（多用双线性内插或三次卷积），指定输出路径生成纠正后的影像。
  5. **精度验证**：利用预留的检查点，查看纠正影像上的点位是否与参考图重合，计算RMSE。

- **影响因素**：控制点(GCP)的精度、数量与分布，地形起伏的复杂程度，原始影像自身的空间分辨率，所选纠正模型的适用程度。

- **提高精度的方法**：
  - 选取足够数量、高精度且均匀分布的控制点，避开高大建筑阴影。
  - 在地形起伏大的区域，必须结合数字高程模型(DEM)进行正射纠正，不能单靠多项式。
  - 对高分辨率影像，引入RPC或严格物理模型替代纯经验多项式。

#### 11. 建立遥感影像构像方程的目的是什么？归纳三个遥感影像纠正模型的特点。
- 建立遥感影像构像方程的目的在于以数学解析的形式，严密表达像点、对应的地面地物点以及传感器投影中心三者之间的空间几何关系 。通过建立物方坐标系与影像空间坐标系之间的转换模型，其主要用途是为遥感影像的几何模型重建、几何纠正以及几何量测提供理论依据，从而实现由像点坐标解算大地坐标（正算）或由大地坐标反求像点坐标（反算） 。

- 1. 共线方程模型
	- 特点：理论严密，能够真实反映传感器的物理构造、成像方式及射线传播的空间几何过程。
	- 适用性与局限：必须已知传感器的精确内外方位元素、姿态角和轨道参数。对于参数未公开的高性能传感器，该模型较难直接应用。
- 2. 有理函数模型
	- 特点：作为严格传感器模型的通用化替代，将像点坐标表示为地面点空间坐标的多项式比值。它不要求用户了解传感器的具体物理细节即可进行纠正处理。
	- 适用性与局限：处理速度快，进行间接法纠正时反算坐标无需迭代；也能像共线方程一样实现前方交会与平差解算 。但该模型通常仅适用于线阵推扫成像，不适用于面阵和线阵摆扫成像。
- 3. 多项式模型
	- 特点：完全回避了成像的空间几何物理过程，直接利用数学多项式将影像的总体变形看作平移、缩放、旋转、偏扭等的综合作用进行模拟，模型简单直观。
	- 适用性与局限：无法真实描述成像过程中的误差来源，也无法消除地形起伏引起的投影变形 。因此，仅适用于畸变极小、地形平坦且范围较小的垂直摄影影像。

#### 12. 给出遥感影像多项式几何纠正的基本原理，遥感影像几何纠正需要地面控制点坐标，其作用是什么？对用于计算多项式系数的控制点有何要求？如何获取其坐标？
- 多项式几何纠正的基本原理：
	多项式几何纠正回避了遥感影像成像时的空间几何物理过程，直接对影像变形的本身进行数学模拟。该方法将遥感影像的总体几何变形看作是平移、缩放、旋转、偏扭、弯曲以及更高次基本变形的综合作用结果，通过构建一个适当次数的多项式，来直接描述纠正前后影像相应点（像点坐标与地图坐标）之间的数学转换关系。

- 地面控制点坐标的作用：
	1. 求解或精化几何纠正模型的未知参数
	2. 提供绝对地理空间基准与地图投影
	3. 参与平差解算以抑制随机误差
	4. 用于几何纠正质量的检验与精度评估

- 对用于计算多项式系数的控制点的要求：
	1. 在影像上必须是明显、清晰的地物特征点（如道路交叉口等），易于准确判读。
	2. 在整幅影像范围内需要均匀分布，避免局部区域误差过大。  
	3. 控制点数量必须足够，通常需要多于未知参数数量的多余观测值。
	4. 控制点自身的坐标精度必须符合既定比例尺或工程的要求。

（3）获取控制点坐标的方式：
	控制点坐标通常通过寻找待纠正影像与已知参考源上的同名点来获取。
	1. 影像与影像对应：从精度较高的已有地形图中读取对应地物点的坐标（地图与影像对应点）。  
    2. 地图（地形图）与影像对应：从已经过几何精纠正且具有地理坐标的标准影像中提取同名点坐标（影像与影像对应点）。
