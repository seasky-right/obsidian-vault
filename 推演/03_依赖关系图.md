# 03_依赖关系图.md

> 用途：解决“架空历史各点互相依赖，AI 前后找不着调”的问题。本文只写节点之间的上游、下游、失败后果，不写正文。

## 0. 依赖类型说明

### 硬前提
没有它，下游设定基本不能成立，必须重写。

### 软增强
没有它，下游仍可发生，但规模、速度、稳定性要下降。

### 制度先例
它不直接造成结果，但让后续制度更容易被想象、追认和合法化。

### 阶级强化
它增强某个集团，让后续政治冲突有主体。

### 反噬约束
它带来收益，也制造新集团坐大、皇权控制下降等副作用。

## A-001 宣德朝不弃交趾，张辅世镇安南

【性质】  
制度先例 + 劳动力入口 + 软增强 + 反噬约束。

【上游依赖】  
- 正史交趾流官制成本过高。  
- 张辅在安南有军事威望。  
- 中央财政存在止损需求。  
- 交趾红河粮区、矿产、港口具有转化潜力。  
- 云南沐氏式世镇边疆提供制度想象。

【支撑下游】  
- 交趾军屯和两广流民安置。  
- 交趾港口成为南洋海商早期法外跳板。  
- 交趾粮成为江南粮食市场第三来源。  
- 交趾市舶司提供关税和南洋接口。  
- 张氏世镇为辽东商屯、蒙古互市、南洋宣慰等“朝廷追认灰色事实”提供先例。  
- 交趾冶铁、火器兵源为民营军工扩散提供南方节点。

【如果失败】  
- 安南独立，交趾线消失。  
- 两广流民南下空间减少。  
- 南洋海商早期安全中转站削弱。  
- 江南粮食市场冗余度下降。  
- 后续“边疆经营可从负担变资产”的制度先例削弱。

【关联节点】  
C-001、D-001、F-001、G-001。

## B-001 天顺盐引违约，北边武装走私转为制度互市

【性质】  
硬前提 + 阶级强化 + 制度先例 + 反噬约束。

【上游依赖】  
- 也先死后蒙古分裂。  
- 明廷九边军费压力长期存在。  
- 开中法和盐引把边商、粮运、军饷绑定在一起。  
- 天顺复辟或类似政治清算引发财政信用危机。  
- 边军断粮和晋商破产形成合谋动机。

【支撑下游】  
- 晋商财阀化。  
- 北方军商集团形成。  
- 蒙古依附互市、债务、宗教和商帮物资。  
- 归化城冶铁、铸锅、农具、边贸用品生产。  
- 辽东商屯和军需运输获得制度参照。  
- 崇祯朝面对北方军商这一承重集团。

【如果失败】  
- 北方军费压力仍高。  
- 晋商不能提前财阀化。  
- 蒙古仍可能维持更强军事威胁。  
- 辽东商屯缺乏晋商资本和边贸经验。  
- 崇祯朝财政压力接近正史。

【关联节点】  
E-001、F-001、G-001。

## C-001 旧港宣慰司被海商借壳，南洋海贸合法化

【性质】  
硬前提 + 资本入口 + 制度先例 + 反噬约束。

【上游依赖】  
- 民间下南洋传统存在。  
- 交趾港口默许走私，提供早期灰色中转。  
- 嘉靖海禁和葡萄牙挤压迫使海商武装升级。  
- 海商需要合法通商权。  
- 朝廷因白银和财政需求需要政治台阶。

【支撑下游】  
- 隆庆开关扩大化。  
- 吕宋华人政权与白银中转。  
- 江南丝织业获得海外订单和白银。  
- 东南海商集团形成。  
- 美洲航线和作物回流。  
- 一条鞭法获得更稳定白银基础。  
- 崇祯朝海贸特许成为财政主权冲突对象。

【如果失败】  
- 白银基础不足，一条鞭法推进不稳。  
- 江南工商业扩张下降。  
- 东南海商集团无法成型。  
- 美洲作物回流推迟。  
- 辽东垦殖强度下降。  
- 士绅—商贾复合体成熟度下降。

【关联节点】  
A-001、D-001、E-001、G-001。

## D-001 美洲作物与白银提前回流

【性质】  
硬前提（对辽东深度垦殖）+ 软增强（对白银财政）+ 技术/物质前提。

【上游依赖】  
- C-001 南洋海贸合法化。  
- 吕宋白银中转。  
- 美洲航线或北太平洋据点。  
- 海商与本土保持定期联系。  
- 闽广和江南有试种与贸易需求。

【支撑下游】  
- 辽东耐寒作物推广。  
- 北方山区灾荒缓冲。  
- 关外流民垦殖扩大。  
- 女真统一空间被压缩。  
- 一条鞭法货币基础增强。  
- 江南工商业获得白银和海外订单。

【如果失败】  
- 辽东线必须降级，不能大规模北推。  
- 后金仍可能形成更大威胁。  
- 北方流民压力上升。  
- 一条鞭法和江南工商业扩张更不稳定。  
- 崇祯朝仍可能面对更重粮荒和流寇压力。

【关联节点】  
C-001、E-001、G-001。

## E-001 辽东流民附籍与商堡垦殖

【性质】  
硬前提（压制后金）+ 劳动力入口 + 阶级强化 + 反噬约束。

【上游依赖】  
- D-001 美洲作物提前回流。  
- B-001 晋商财阀化和边贸经验。  
- 关内土地兼并与流民压力。  
- 辽东都司控制薄弱但仍有明廷名义。  
- 朝廷一条鞭法方向下有纳税人口动机。

【支撑下游】  
- 辽东汉城体系成熟。  
- 女真部落被分化、买办化、附庸化。  
- 努尔哈赤式统一空间压缩。  
- 后金无法做大，辽饷黑洞消失。  
- 辽东成为流民泄洪区、税源、兵源、军工节点。  
- 关东军商 / 辽东边镇集团形成。

【如果失败】  
- 后金或类似女真政权仍可能崛起。  
- 辽饷黑洞重新出现。  
- 崇祯朝财政压力大幅增加。  
- 北方流民无泄洪区，流寇问题加重。  
- 关东军商集团缺席，崇祯政治格局少一方力量。

【关联节点】  
B-001、D-001、F-001、G-001。

## F-001 民营军工以辽东边防需求为入口合法化

【性质】  
硬前提（产业资本形成）+ 制度先例 + 资本锁链突破 + 反噬约束。

【上游依赖】  
- E-001 辽东垦殖和商堡武装需要军器。  
- B-001 归化城冶铁和北方军商技术积累。  
- C-001 东南海商吸收造船、火炮技术。  
- 官营军器局低效。  
- 朝廷边防和军需压力。

【支撑下游】  
- 《辽东军器采办事例》。  
- 民营军工扩散到交趾、佛山、东南沿海、归化城。  
- 万历矿政改制。  
- 商业资本转入矿山、冶铁、军工、造船。  
- 士绅—商贾复合体从商业资本进一步产业化。  
- 崇祯朝围绕军工和矿山特许发生收权冲突。

【如果失败】  
- 资本锁链难以从流通资本进入重工业。  
- 商帮仍以买地、放贷、贸易为主。  
- 产业资本家群体不足。  
- 崇祯朝冲突更偏财政税收，少了军工和矿山产权维度。  
- 辽东、南洋、交趾的武装能力下降。

【关联节点】  
B-001、C-001、E-001、G-001。

---

## G-001 崇祯朝财政主权冲突

【性质】  
上层建筑总爆发 + 反噬约束。

【上游依赖】  
- A-001 交趾省化、粮源、港口和南方军政集团。  
- B-001 北方军商集团成型。  
- C-001 东南海商集团成型。  
- D-001 白银和作物回流增强市场。  
- E-001 关东军商集团成型，后金危机压低。  
- F-001 民营军工、矿政、产业资本形成。  
- 天启朝内廷保护伞存在且崇祯继位后瓦解。

【支撑下游】  
- 崇祯第一次收权动作。  
- 士绅、海商、军商、边镇的反应选择。  
- 经世派官员调停。  
- 议饷、报效、特许定额、军工采办制度化。  
- 旧明制外壳下的财政共治雏形。  
- 17 世纪后半至 18 世纪权力重组。

【如果失败】  
- 如果皇权轻松收回特许，体制内革命无从发生。  
- 如果集团直接叛乱，则变成军阀割据或内战，不再是体制内革命。  
- 如果各集团互相出卖，皇权可逐个击破。  
- 如果经世派不能调停，制度化妥协难以形成。

【关联节点】  
A-001、B-001、C-001、D-001、E-001、F-001。

## 使用方式

每次给 AI 审某一片段时，只复制：

1. `00_推演规则.md` 的核心规则；
2. 当前片段；
3. 本文件中该片段相关节点的“上游依赖 / 下游影响 / 失败后果”；
4. 明确任务：只审上下游是否成立，不要续写。

示例：

```text
请审查“辽东 / 女真线”。

上游依赖：
- D-001 美洲作物与白银提前回流
- B-001 北方军商集团成型
- F-001 民营军工入口

下游影响：
- 女真统一空间被压缩
- 后金无法做大
- 辽东成为流民泄洪区和军工节点
- 关东军商集团形成

请只检查：上游是否足以支撑当前节点？当前节点是否能推出下游？哪些地方需要降级？
```
