
> yong y用于回答“谁得利、谁失利、谁推动改革、谁反扑”，是后续推演的角色表和利益表。

## 0. 总原则

从马克思主义阶级观的角度，本推演的核心为：

> 官僚统治阶级内部资产阶级化。

即：

- 士绅家族开始投资丝织、棉纺、冶铁、矿山、军工、海贸、金融。
- 商贾通过捐纳、联姻、科举、会馆、书院、地方官僚网络进入士绅体系。
- 边军、商帮、地方督抚、海外侨社和宗族共同形成复合集团。
- 所有集团都继续使用旧制度语言表达新利益。

## 1. 皇权 / 内廷财政集团

【经济基础】  
内库、皇庄、税使、矿税、商税、报效银、贡舶抽分、特许权发放、军需采办审批。

【组织形态】  
皇帝、司礼监、内廷宦官、内库系统、宫廷采办、部分依附内廷的商帮和税务代理人。

【政治通道】  
圣旨、内批、司礼监批红、厂卫监察、税使派遣、特许权授予和收回。

【武力 / 技术 / 地方控制】  
厂卫、锦衣卫、内操、税使随从、皇权名义、对地方官的监察权。

【核心诉求】  
恢复皇权对财政、人事、税权、军权和特许权的直接掌控；防止士绅、商帮、边镇坐大。

【害怕什么】  
财政被户部、地方督抚、商帮、边镇架空；内廷保护伞因阉党问题被清算；皇权只剩名义。

【支持什么制度】  
临时加派、报效、查税、重发特许、内廷直接征收、税使监察。

【反对什么制度】  
特许权稳定化、商税定额化、财政共治、地方督抚与商帮长期协议。

【崇祯朝立场】  
崇祯清算阉党后，内廷保护伞瓦解。皇权天然倾向反扑，但必须面对商帮、海商、边镇已嵌入财政和军需的现实。

【与其他集团关系】  
- 可利用经世派官员重整财政。  
- 可拉拢某一商帮打击另一商帮。  
- 与士绅—商贾复合体、东南海商、北方军商、关东军商都存在特许权冲突。  
- 与保守士绅可临时结盟打击商税、矿税、海贸，但会损害新财政来源。

## 2. 传统士绅地主集团

【经济基础】  
土地、地租、佃农、人身依附、宗族义田、乡村高利贷、地方税粮代理。

【组织形态】  
宗族、乡约、书院、地方缙绅、科举网络、乡村保甲。

【政治通道】  
科举、地方官、言官、乡绅舆论、书院讲学、地方公议。

【武力 / 技术 / 地方控制】  
宗族武装、乡勇、保甲、粮仓、祠堂、族规、地方舆论。

【核心诉求】  
维持土地收益、佃农稳定、乡村秩序、低商税或由自身控制地方税收。

【害怕什么】  
流民离乡导致佃农减少；工商业吸走劳动力；商税、矿税、海税使国家财政不再完全依赖田赋；产业化士绅抢夺地方话语权。

【支持什么制度】  
清逃、回籍、限制作坊吸纳流民、维护主佃关系、地方自治式乡绅治理。

【反对什么制度】  
工籍、附籍、流民自由迁移、矿山和军工吸纳劳动力、海贸资本坐大。

【崇祯朝立场】  
内部发生分裂。纯农业地主倾向支持皇权或保守清流限制商帮；兼营工商业者则转入士绅—商贾复合体。

【与其他集团关系】  
- 与士绅—商贾复合体有同源关系但利益分裂。  
- 与流民/工籍劳动者存在控制与流失矛盾。  
- 可被皇权用来反制商帮，也可能被商帮通过联姻、债务、投资吸纳。

## 3. 士绅—商贾复合体

【经济基础】  
江南丝织、棉纺、作坊、金融、典当、钱庄、海贸信贷、矿山投资、军工投资、土地和科举资源。

【组织形态】  
宗族、会馆、书院、商帮、作坊网络、金融网络、科举官僚网络。

【政治通道】  
科举、地方官、言官、内阁、户部、地方督抚、捐纳、联姻、书院舆论。

【武力 / 技术 / 地方控制】  
团练、保甲、作坊工人、地方乡勇、账房金融技术、织造技术、舆论控制。武力弱于边镇和海商，但地方社会控制力强。

【核心诉求】  
产权稳定、商税可预期、海贸合法、作坊雇工合法、矿山和军工投资可持续、反对皇权任意查抄。

【害怕什么】  
皇权临时加派、内廷税使、矿禁恢复、海禁反复、任意没收产业资产、保守士绅清流攻击“与商争利”。

【支持什么制度】  
附籍、工籍、一条鞭法、商税定额、海贸特许、矿政承包、军器采办制度化、财用合议。

【反对什么制度】  
任意查税、抄没、全面禁海禁矿、强制流民回籍、恢复官营垄断。

【崇祯朝立场】  
表面忠君，实质要求限制皇权财政任意性。可能推动“议饷协商”而非公开反皇权。

【与其他集团关系】  
- 与东南海商形成白银、丝织、信贷闭环。  
- 与北方军商有金融和政治竞争。  
- 与关东军商在军工、矿山、边贸上有合作。  
- 与皇权既合作又冲突。  
- 与传统士绅同源但分化。

## 4. 北方军商集团

【经济基础】  
蒙古互市、盐茶铁器、砖茶、棉布、粮食、边贸抽分、九边军需、归化城商业、草原债务和贸易配额。

【组织形态】  
晋商商帮、边镇将门、商队、镖师、武装商堡、边军家丁、蒙古附庸、归化城寺庙网络。

【政治通道】  
边镇总兵、巡抚、总督、户部、兵部、互市特许、顺义王册封体系、寺庙供养和僧侣册封。

【武力 / 技术 / 地方控制】  
边军家丁、商团镖师、蒙古附庸骑兵、商堡、粮仓、铁器和军需供应链。

【核心诉求】  
互市稳定、贸易配额稳定、九边军需外包合法、边贸税源由集团主导、草原秩序可控。

【害怕什么】  
朝廷突然禁市、查抄晋商、恢复中央直接军需、蒙古强人脱离贸易体系、南方海商抢夺财政话语权。

【支持什么制度】  
北边互市法、贸易抽分、商帮报效、边镇军需承包、归化城宗教商业中心、册封体系。

【反对什么制度】  
禁市、查商、强行调拨边商资产、剥夺商堡武装、中央直接控制九边供应。

【崇祯朝立场】  
可被皇权拉拢以制衡江南和东南，也可能因互市、税权、军需承包被皇权收权而抵制。

【与其他集团关系】  
- 与关东军商关系密切，共享晋商、鲁商、军需和边贸网络。  
- 与东南海商并列为两大财阀力量。  
- 与皇权有强依赖关系但反对任意查抄。  
- 与蒙古上层形成债务和婚姻纽带。

---

## 5. 东南海商 / 海外华人集团

【经济基础】  
旧港宣慰司、吕宋白银中转、南洋香料、港口关税、船队护航、美洲航线、毛皮贸易、海外华人公司和侨社。

【组织形态】  
闽广海商家族、武装船队、海外宣慰司、吕宋华人政权、婆罗洲公司、侨社、会馆、港口商团。

【政治通道】  
市舶司、贡舶、旧港宣慰司名义、地方督抚、江南士绅信贷保护、朝贡旧制、报效银。

【武力 / 技术 / 地方控制】  
远洋舰队、炮舰、船厂、海员、船工、港口武装、南洋据点、航海技术、火炮技术。

【核心诉求】  
海贸合法、港口开放、南洋据点名义合法、贡舶/市舶体系稳定、禁止朝廷突然禁海。

【害怕什么】  
海禁恢复、内廷税使敲诈、朝廷将海商重新定性为海盗、欧洲势力冲击、江南信贷断裂。

【支持什么制度】  
市舶合法化、多口岸开放、贡舶追认、海外宣慰司、海贸税定额、船队护航合法。

【反对什么制度】  
禁海、迁界、查抄船队、强制收编海外据点、过度太监税使。

【崇祯朝立场】  
强烈反对皇权直接收回海贸和南洋特许。可能以白银生命线要挟朝廷，也可能与江南士绅联合推动协商化。

【与其他集团关系】  
- 与江南士绅—商贾复合体形成金融和订单闭环。  
- 与交趾地方集团共享港口和南洋通道。  
- 与皇权通过贡舶、市舶和报效维持合法关系。  
- 与北方军商在财政话语权上竞争。

## 6. 关东军商 / 辽东边镇集团

【经济基础】  
辽东垦殖、汉城堡寨、人参、貂皮、东珠、沙金、边贸、军需、民营军工、女真附庸劳动力。

【组织形态】  
辽东本土汉人垦殖者、辽东边军、晋商鲁商、商镇堡寨、会馆、采参客、采矿集团、团练武装、女真附庸部落。

【政治通道】  
辽东都司、边将、地方州县、贸易特许、军器采办、附籍制度、女真册封。

【武力 / 技术 / 地方控制】  
本土边兵、商堡护院、采参武装、民营军工、女真附庸骑兵、堡寨网络、辽东城镇体系。

【核心诉求】  
辽东附籍稳定、商屯合法、军工特许稳定、边镇财政自主、对女真部落的经济控制合法。

【害怕什么】  
朝廷收回军工特许、清查商堡武装、强行调辽东兵入关、女真反叛、晋商资金断裂。

【支持什么制度】  
就地附籍、低税垦殖、辽东贸易特许、军器采办、堡寨合法化、女真册封和抚赏。

【反对什么制度】  
恢复单纯卫所军管、驱逐流民、禁止商堡、中央直接收回军工和边贸。

【崇祯朝立场】  
名义忠君，实质要求保留辽东地方军事和经济自主。可被皇权倚重平叛，也可能因收权而变成压力源。

【与其他集团关系】  
- 与北方军商共享晋商网络和边贸制度。  
- 与士绅—商贾复合体在军工、矿山、金融上合作。  
- 与皇权是兵源合作关系，也有调兵与税权冲突。  
- 与女真附庸群体存在雇佣、买办、压迫和通婚关系。

## 7. 交趾地方军政集团

【经济基础】  
红河三角洲粮食、交趾港口、市舶司、铜银矿、军屯、南方兵源、民营军工节点。

【组织形态】  
张氏旧勋贵、卫所军官、两广移民士绅、本地归附士绅、土司、商帮、港口官商网络。

【政治通道】  
交国公旧特权、改土归流后府县体系、两广总督或交趾布政使司、市舶司、军功和科举通道。

【武力 / 技术 / 地方控制】  
南方火器兵、卫所残余、地方团练、港口武装、矿山工匠、交趾冶铁节点。

【核心诉求】  
维护交趾省化后的地方利益、市舶收益、粮贸、矿产特许、南洋中转地位。

【害怕什么】  
中央重新清算张氏旧权、取消市舶和矿产特许、两广或江南商帮夺取本地港口收益、本地反抗死灰复燃。

【支持什么制度】  
改土归流后的地方府县化、市舶合法化、矿产承包、南洋贸易中转、交趾粮贸。

【反对什么制度】  
重新军事化管制、禁海、取消地方税源、过度中央派官清查。

【崇祯朝立场】  
大概率观望。可向皇权提供粮、兵、港口，也可与东南海商和两广士绅联动抵制过度收权。

【与其他集团关系】  
- 与东南海商共享南洋通道。  
- 与士绅—商贾复合体共享江南布—交趾粮—南洋银贸易。  
- 与皇权保持名义忠诚。  
- 与两广宗族和商帮深度融合。

## 8. 经世派官员 / 技术官僚群体

【经济基础】  
本身不构成独立经济集团，依附于国家财政、六部、督抚和专业行政岗位。

【组织形态】  
户部、兵部、工部、地方督抚、河道、矿政、军工、市舶、边务、税务系统中的专业官员。

【政治通道】  
科举、奏疏、部议、督抚实践、内阁调停、皇权任用。

【武力 / 技术 / 地方控制】  
没有独立武力，但掌握财政核算、军需调度、矿政管理、市舶制度、边务和工程技术。

【核心诉求】  
以可持续财政和制度化管理维持国家运转，反对短视查抄和非理性禁令。

【害怕什么】  
皇权情绪化收权破坏税源；士绅清流以道德话语否定技术财政；商帮完全架空国家；边镇坐大成割据。

【支持什么制度】  
议饷、财用合议、商税定额、军工采办、矿政承包监管、海贸特许制度化、边镇财政核算。

【反对什么制度】  
任意查抄、全面禁海、全面禁矿、无预算加派、直接破坏市场税源。

【崇祯朝立场】  
最可能成为皇权争取的同盟，但也是最先站出来以专业论证抵制非理性政策的力量。

【与其他集团关系】  
- 与皇权合作重整财政。  
- 与士绅—商贾复合体在制度化诉求上有交集。  
- 与商帮存在监管与合作关系。  
- 与保守士绅存在理念冲突。

## 9. 流民 / 工籍劳动者 / 矿工 / 船工 / 军工工匠

【经济基础】  
出卖劳动力，进入作坊、矿场、船厂、军工、商堡、垦殖区、南洋据点。

【组织形态】  
机工、矿工、船工、军工工匠、商堡护院、采参客、码头劳力、垦殖民。组织性弱，但数量庞大。

【政治通道】  
基本没有独立政治通道，只能通过机户、商帮、地方官、边镇、宗族、会馆被间接表达。

【武力 / 技术 / 地方控制】  
部分工匠掌握技术；商堡护院、船工、军工劳动者有一定武力经验；整体缺乏独立政治组织。

【核心诉求】  
生存、稳定雇佣、附籍合法、免于遣返、工资和粮食保障、避免被重新绑定为奴仆或佃农。

【害怕什么】  
清逃回籍、失业、饥荒、工场倒闭、商帮逃资、官府强征、战争。

【支持什么制度】  
附籍、工籍、就地纳税、作坊合法、垦殖合法、南洋出海入籍。

【反对什么制度】  
强制遣返、禁工、禁矿、禁海、恢复匠籍劳役、过度差役摊派。

【崇祯朝立场】  
不会形成统一集团，但会成为各集团动员、雇佣、压榨或安抚的对象。若吸纳机制崩溃，仍可能转化为流寇、矿工暴动、城市工变或海盗。

【与其他集团关系】  
- 被士绅—商贾复合体雇佣。  
- 被东南海商招募为船工和海外移民。  
- 被关东军商吸纳为垦殖民和护院。  
- 被皇权视为税源和治安风险。

## 10. 边疆附庸群体

【经济基础】  
蒙古部落的马匹、皮毛、畜牧；女真部落的人参、貂皮、东珠、狩猎；安南土司、本地豪族的土地和基层控制；南洋华人侨社和当地土著合作网络。

【组织形态】  
部落、土司、宣慰司、侨社、买办、雇佣兵、寺庙护卫、商路护卫。

【政治通道】  
册封、都督同知、顺义王、宣慰使、土司、贡舶、互市配额、商帮债务。

【武力 / 技术 / 地方控制】  
草原骑兵、山地武装、女真猎兵、土司兵、南洋港口武装。

【核心诉求】  
获得贸易配额、册封合法性、物资供应、地方自主和生存空间。

【害怕什么】  
贸易断绝、商帮债务控制、汉人垦殖挤压、朝廷清剿、强人失败后被抛弃。

【支持什么制度】  
互市、册封、宣慰、土司、贡舶、商帮保护、寺庙供养。

【反对什么制度】  
直接流官化、贸易封锁、强制迁徙、商帮过度债务控制。

【崇祯朝立场】  
一般不直接进入中央政治，但会作为各大集团的附庸武力、贸易伙伴或边疆压力源参与冲突。

【与其他集团关系】  
- 蒙古依附北方军商。  
- 女真依附关东军商。  
- 安南本地豪族融入交趾地方集团。  
- 南洋侨社依附东南海商。
