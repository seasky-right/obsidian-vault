## 0. 项目定位

本推演的终极目标为：

> 明朝中央政权延续至 18 世纪，并发生一场非西方路径的、基于中国社会内部阶级演化的“资产阶级（士绅—商贾复合体）体制内革命”。

本推演使用的基本解释框架是：

> 内部经济矛盾外溢 → 边疆与海贸压力场形成 → 生产要素重新配置 → 劳动力、资本、制度三条锁链松动 → 利益集团生成 → 皇权与新利益集团发生财政、军工、海贸、边镇控制权冲突 → 旧明制外壳下出现中国式权力重组。

## 1. 最高规则

1. 不允许把“明朝不缩边”当作强大的根本原因。
2. 边疆与海贸不是目的，而是内部矛盾外溢后的压力场。
3. 所有重大变化必须回到第二部“市场松动与资本生成”。
4. 所有地缘收益必须先写成本，再写转化机制。
5. 所有发展必须有副作用，不能只让明朝变强。
6. 所有制度变化都不能写成现代政策发布，而要写成旧制度中的追认、特许、承包、妥协、报效、议饷、督抚协调。
7. 除非明确要求，否则不得直接续写剧情。默认任务是审稿、拆链、找漏洞、整理结构。

## 2. 因果链规则

每个重要设定都必须回答：

- 正史中本来发生了什么？
- 本时间线改动了哪个最小变量？
- 这个变量为什么在正史条件下有可能发生？
- 1—5 年内造成什么直接结果？
- 10—30 年内改变什么经济结构？
- 30—100 年内如何改变阶级关系与制度结构？
- 它接入了哪条锁链：劳动力、资本、制度？
- 它增强了哪个集团，削弱了哪个集团？
- 它制造了什么反噬？

禁止写法：

```markdown
- 因为明朝更英明，所以改革成功。
- 因为皇帝想通了，所以制度改变。
- 因为多了一块地，所以国家变强。
- 因为商人有钱，所以自动形成资产阶级。
- 因为火器/白银/作物出现，所以社会自动近代化。
```

推荐写法：

```markdown
- 因为旧制度无法处理某种财政、军需、流民、市场压力，地方先形成灰色事实，朝廷再以旧制度语言追认。
- 因为某个集团在旧制度中获得新经济功能，所以它开始要求更稳定的特许权、产权、税权和政治通道。
- 因为皇权依赖这些集团提供财政、兵源、军工或海贸收益，所以不能简单查抄；但皇权仍试图反扑，由此产生冲突。
```
## 3. 第二部接入规则

所有章节必须能够接入以下三条锁链之一，最好能同时接入两条以上。

### 3.1 劳动力锁链

正史状态：

- 农民被土地、户籍、差役、佃租关系绑定。
- 军户、匠户、民户身份固定。
- 流民被视为逃户、盲流、治安问题。

松动方式：

- 交趾军屯、垦殖吸纳两广流民。
- 辽东私垦、就地附籍吸纳关内流民。
- 南洋据点吸纳闽广船工、工匠、逃户、破产农民。
- 江南作坊吸纳城市机工。
- 工籍、附籍、出海入籍等制度追认使流民从非法人口变成可纳税、可雇佣、可组织的人口。

校核问题：

- 这一设定是否释放了某类劳动力？
- 这些劳动力为什么不能按正史方式被遣返？
- 谁需要这批劳动力？
- 朝廷为什么愿意追认？

### 3.2 资本锁链

正史锁死状态：

- 商业资本主要出路是买地、放贷、捐官、供子弟科举。
- 产业投资受矿禁、匠籍、官营垄断、皇权任意查抄制约。

松动方式：

- 北边互市使晋商财阀化。
- 南洋海贸使闽广海商、江南士绅资本闭环。
- 辽东商屯、堡寨、军需使商帮资本进入边疆垦殖和军工。
- 民营军工、矿政改制、造船、冶铁提供产业投资出口。

校核问题：

- 这一设定是否给资本提供了比买地、放贷更高或更稳定的回报？
- 资本为什么敢投？
- 谁提供政治保护？
- 失败时资本会怎样反噬政治？

### 3.3 制度锁链

正史锁死状态：

- 海禁、矿禁、盐铁专卖、匠籍、官营军工。
- 国家对关键生产资料和技术劳动力直接控制。
- 商人合法性不稳定，特许权随时可能被收回。

松动方式：

- 走私、私矿、民间冶铁、武装海商先形成事实。
- 朝廷因财政、军需、边防压力被迫追认。
- 国家从直接经营退到特许、承包、征税、监管。
- 特许不是现代产权，而是旧制度内部的半合法空间。

校核问题：

- 这一制度变化是否有地方先例？
- 谁支持？谁反对？
- 皇权为什么让步？
- 让步之后谁坐大？
- 是否埋下崇祯朝收权危机？

## 4. 阶级与集团规则

推演中不应当直接套用现代“资产阶级—无产阶级”二分法。

核心概念为：

> 官僚统治阶级内部资产阶级化。

即：

- 士绅家族不再只靠土地、功名、宗族和官职，而开始投资丝织、棉纺、冶铁、矿山、军工、海贸、金融。
- 商人也通过捐纳、联姻、科举、攀附官僚进入士绅体系。
- 最终形成了并非纯粹现代资产阶级，而是士绅—商贾复合体、军商集团、海商集团、边镇集团等旧制度内部的新功能集团。

对于每个集团，必须回答：

- 经济基础是什么？
- 组织形态是什么？
- 政治通道是什么？
- 武力/技术/地方控制来自哪里？
- 核心诉求是什么？
- 害怕什么？
- 支持什么制度？
- 反对什么制度？
- 崇祯朝站在哪一边？

## 5. 崇祯以后推演规则

崇祯朝的核心冲突应当为：

> 谁有权收钱、用钱、造兵器、开矿、通海、养兵。

已知前提：

- 后金危机被压低，辽饷黑洞大幅减轻。
- 交趾、辽东、蒙古、南洋、江南都提供新的资源、粮源、税源和兵源。
- 士绅—商贾、北方军商、东南海商、关东军商、内廷财政集团已经成型。
- 天启朝内廷保护伞被崇祯清算阉党打断。
- 特许权仍来自皇权追认，皇权仍可能试图收回。

推演崇祯朝时必须避免：
```markdown
- 直接写成崇祯“更聪明所以成功”。
- 直接写成各集团自动让步。
- 直接写成现代议会或君主立宪。
- 忽略旧制度语言：祖宗成法、恤民、安边、护商、贡舶、互市、议饷、报效、特许。
```

推荐方向：

```markdown
- 崇祯第一次收权动作引发财政主权冲突。
- 经世派官员在皇权与商帮之间调停。
- 危机从“查税收权”被迫转向“议饷协商”。
- 最终可能形成某种旧明制外壳下的“财用合议”或“内阁—六部—督抚—商帮代表”协商机制。
```
## 6. 给 AI 的标准任务模板

### 6.1 逻辑审查模板

```markdown
请只做逻辑审查，不要续写剧情。

重点检查：

1. 分歧点是否是正史中可能发生的最小变量；
2. 是否把地缘扩张误写成根本原因；
3. 是否接入劳动力、资本、制度三条锁链；
4. 是否说明了支持者、反对者和皇权让步原因；
5. 是否制造了副作用；
6. 是否与上游依赖和下游结果一致；
7. 哪些地方需要补正史依据。
```
### 6.2 因果链拆解模板

```markdown
请将以下片段拆成：

正史节点 → 最小变量 → 直接结果 → 中期经济变化 → 阶级变化 → 制度变化 → 反噬风险 → 与其他线接口。

无法推出的地方标记为【跳跃】。
```
### 6.3 反方审稿模板

```markdown
请作为保守明史研究者反驳以下设定。

重点反驳：

1. 人物动机是否成立；
2. 制度惯性是否允许；
3. 财政、交通、技术条件是否支撑；
4. 地方集团是否会反噬；
5. 有没有更可能发生的替代结果。

不要润色，不要续写，只反驳。
```
